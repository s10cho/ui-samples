## 8. 미확인

- 375 터치 200% 날짜 칸: 3회차 채점자는 다시 재지 않았다. 오케스트레이터 측정은 44.4 다.
- 실제 키 입력: 채점 도구에 없어 합성 이벤트로 확인했다. 작성자는 CDP 실제 키 입력으로 1~4단계를 확인했다고 보고했다(검증되지 않음).
- axe: 채점자는 돌리지 못했다. 저장소 CI(check-pages)가 상태 6개를 데스크톱·모바일에서 돌려 위반 0, 전송량 128.7KB/150KB 다(오케스트레이터 실행).
