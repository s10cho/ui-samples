## 7. 미확인

- 실제 키 입력(Tab·Enter·Esc·⌘Enter): 채점 도구에 키 입력이 없어 합성 이벤트로만 확인했다.
- axe: 채점자는 돌리지 못했다. 저장소 CI(check-pages, Playwright + axe)가 같은 상태 6개를 데스크톱·모바일에서 돌려 위반 0 이다(작성자 실행).
- 글자 200% 는 뿌리 글자 32px 로 재현했다. 이 방식에서는 rem 미디어 경계가 바뀌지 않는다.
