## 6. 상호작용

| 동작 | 마우스·터치 | 키보드 | 결과 |
|---|---|---|---|
| 묶음으로 이동 | 옆 메뉴 링크 | Tab · Enter | 그 묶음으로 스크롤, 옆 메뉴의 지금 위치가 바뀐다. 서랍이면 닫힌다 |
| 옆 메뉴 서랍 | 메뉴 버튼, 가림막 누르기 | Enter, Esc | 서랍이 열리면 첫 링크로, 닫히면 메뉴 버튼으로 포커스 |
| 화면 밝기 | 묶음 버튼 | 화살표 · Home · End | 바로 바뀌고 저장한다(`ds-theme`) |
| 표 정렬 | 머리 버튼 | Enter · Space | 오름·내림 차례로, 화면낭독기에 "건수 오름차순으로 정렬했어요", 주소 `?sort=` |
| 표 필터 | 칩 | Enter · Space | 행이 걸러지고 개수가 바뀐다, 주소 `?status=` |
| 행 고르기 | 체크박스 | Space | 고른 행 바탕, "2개 고름" 과 일괄 동작이 보인다 |
| 탭 | 탭 버튼 | ← → Home End | 패널이 바뀌고 주소 `?tab=` |
| 메뉴 | 메뉴 버튼 | ↓ ↑ Esc | 첫 항목으로 포커스, Esc 로 닫고 버튼으로 |
| 대화상자 | "보고서 지우기…" | Tab 은 대화상자 안에서만 돈다, Esc | 닫으면 연 버튼으로 포커스 |
| 배너 띄우기 | 버튼 | Enter | 배너 자리로 스크롤, 닫거나 "되돌리기"를 누르면 포커스가 "배너 띄워 보기"로 |
| 옆 패널 | "옆 패널 열기" | Enter, 패널 안 닫기 | 1280 이상은 붙고 그보다 좁으면 덮는다. 닫으면 연 버튼으로 |
| 쪽 넘기기 | 쪽 번호 | Enter | 주소 `?page=` 와 지금 쪽 표시가 바뀐다(새로 불러오지 않음) |

- 단축키: 없음.

## 10. 설계 메모 — 흔한 기본값과 비교

| 처음 안 | 흔한 기본값과 같은 점 | 바꾼 것 |
|---|---|---|
| 부품마다 카드 하나씩 격자로 늘어놓기 | 같은 카드를 같은 반경·그림자로 격자에 늘어놓는 키트 화면(`SLOP-06`) | 묶음은 카드 없이 제목 + 설명 + 예시로 둔다. 상태는 표(행 = 변형, 열 = 상태)로 비교한다 |
| 첫 영역에 큰 제목 + 그라데이션 띠 | 히어로 영역(`SLOP-10`) | 제목 한 줄 + 설명 한 줄. 바로 첫 묶음(색)이 보인다 |
| 견본 칩마다 테두리 상자 + 그림자 | 모든 것을 테두리 상자로 감싼 구성(`SHP-05`) | 견본은 색 칸 + 이름 두 줄. 칸에만 옅은 테두리 |
| 강조색으로 옆 메뉴 지금 위치 칠하기 | 강조색을 내비·헤더에 씀(`CLR-08`) | 지금 위치는 회색 바탕 + 굵기 |
| 마우스 올림·포커스를 실제로 해 봐야만 보이게 | — | 상태 표에 `.is-hover`·`.is-focus` 로 멈춰 둔 칸을 둔다. 실제 동작은 옆 칸의 진짜 부품으로 해 본다 |
