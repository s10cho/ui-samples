업무 화면 샘플이 함께 쓰는 토큰과 부품을 상태별로 모았어요. 값은 저장소의 DESIGN.md와 같아요.

표와 목록의 이름·숫자는 지어낸 예시예요.

색

부품은 역할 이름이 붙은 색만 써요. 오른쪽 값은 지금 고른 화면 밝기에서 읽은 값이에요.

--ds-color-surface-* · fg-* · fill-* · line-* · 그래프 series-1~6(강조색은 그래프에 쓰지 않아요. 밝은 UI 3·4·5번은 바탕 대비가 3:1 미만이라 범례와 직접 표기, 또는 표 보기를 함께 둬요) · 어두운 UI <html data-theme="dark">
