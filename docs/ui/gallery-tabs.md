| 나가는 길 | 샘플 열기, 코드 보기, 화면 설계서, 검수 보고서 | 확인 — 지금 카드 |

## 2. 정보 우선순위

| 순위 | 정보·행동 | 이 순위인 이유 |
|---|---|---|
| 1 | 계열 탭(전체 · 업무 화면 · 모바일 · 3D 장면 · 2D 그림판)과 계열마다 샘플 수 | 계열이 넷으로 늘어 한 줄로 나열하면 원하는 것을 찾기 어렵다 |
| 2 | 고른 계열의 설명 한두 줄 | 계열마다 만든 방법(공용 부품·Three.js·SVG)이 다르다 |

- 주 행동: 샘플 열기(카드마다). 탭은 거르기다.

## 3. 영역 구성

| 영역 | 위치 | 담는 것 | 컴포넌트 | 좁은 폭(320~375) | 중간 폭(768) | 넓은 폭(1280 이상) |
|---|---|---|---|---|---|---|
| 소개 | 위 | 제목 "UI 샘플", 두 줄 소개 | 지금 그대로 | 그대로 | 그대로 | 그대로 |
| 계열 탭 | 소개 아래 | 링크 5개: 전체 23 · 업무 화면 13 · 모바일 1 · 3D 장면 6 · 2D 그림판 3. 현재 탭은 굵기 + 아래 막대 + `aria-current` | `<nav aria-label="샘플 계열">` 안 링크 목록 | 줄바꿈으로 2줄까지(가로 스크롤로 숨기지 않는다). 누르는 높이 44 | 한 줄 | 한 줄 |
| 계열 묶음 | 탭 아래 | 계열 제목·설명·카드 격자. "전체"면 모든 계열을 지금처럼 위아래로 | 지금 `section.group` | 1열 | 2열 | 3~4열 |
| 바닥 | 아래 | 지금 그대로 | — | — | — | — |

- 붙는 탭 줄로 만들지 않는다. 좁은 폭 + 큰 글자에서 화면을 덮는 문제를 업무 화면에서 여러 번 겪었다.
- 계열 순서: 업무 화면 → 모바일 → 3D 장면 → 2D 그림판. 디자인 시스템·패턴 분석이 저장소 목적이라 UI 계열을 앞에 둔다(열린 질문 2).

## 4. 컴포넌트

| 컴포넌트 | 기존 / 새로 | 변형 | 쓰는 토큰 | 관련 규칙 |
|---|---|---|---|---|
| 계열 탭 | 새로(목록 페이지 안) | 링크 + 현재 표시(굵기·막대) | 페이지 `:root` 의 `--c-accent` `--c-line` `--target` `--space-*` | `CMP-NAV-05` `CMP-NAV-06` `CMP-NAV-11` `CMP-NAV-12` |
| 계열 묶음·카드 | 기존 | — | 지금 그대로 | — |

- 새로 만드는 이유: 목록 페이지는 kit 을 쓰지 않는 단독 페이지다. 탭 하나 때문에 kit 을 싣지 않는다.
- 탭은 `role="tablist"` 가 아니라 링크로 만든다. 탭마다 주소가 있고(`#group-3d`), 스크립트가 없어도 그 계열로 이동해야 하기 때문이다.

## 6. 상호작용

| 동작 | 마우스·터치 | 키보드 | 결과 |
|---|---|---|---|
| 계열 바꾸기 | 탭 누름 | Tab → Enter | 주소 해시가 `#group-<id>` 로 바뀐다. 그 계열만 보이고, 포커스는 그 계열 제목으로 간다. 결과를 `role="status"` 로 알린다 |
| 전체 보기 | "전체" 누름 | Tab → Enter | 해시가 지워지고 모든 계열이 보인다 |
| 뒤로 가기 | 브라우저 뒤로 | 같음 | 앞서 본 탭으로 돌아간다(해시 기록) |
| 공유 | 주소 복사 | 같음 | 받은 사람이 같은 탭으로 연다 |

- 포커스 순서: 소개 → 계열 탭 → 고른 계열 제목 → 카드.
- 움직임 없음. 탭을 바꿔도 나타나기만 한다.

## 10. 설계 메모 — 흔한 기본값과 비교

| 처음 안 | 흔한 기본값과 같은 점 | 바꾼 것 |
|---|---|---|
| ARIA 탭(`role="tab"`) + 화살표 키 | 내용 전환 탭의 흔한 구현 | 링크 + 해시. 탭마다 주소가 있고 스크립트 없이도 이동한다 |
| 탭 줄을 화면 위에 붙이기 | 붙는 필터 줄 | 붙이지 않는다(좁은 폭 + 큰 글자에서 화면을 덮는다) |
| 좁은 폭에서 탭 줄 가로 스크롤 | 흔한 모바일 탭 줄 | 줄바꿈 — 끝 탭이 화면 밖으로 숨지 않게(검색 결과 샘플 검수에서 지적) |

## 13. 구현과 검수 기록(2026-11-18)

| 단계 | 결과 | 고친 것 |
