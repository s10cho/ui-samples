## 4. 영역 구성

| 영역 | 담는 것 | 좁은 폭(320~767) | 중간 폭(768~1023) | 넓은 폭(1024 이상) |
|---|---|---|---|---|
| 첫 화면 글 | h1, 소개 2줄, 요약 문장, 버튼 "샘플 둘러보기" · 링크 "저장소 보기", 안내 1줄 | 위 | 위 | 왼쪽, 세로 가운데. 글 칸 27rem(80rem 이상 32rem) |
| 화면 벽 | 샘플 썸네일 기둥 3~4개. 기둥마다 위아래로 천천히 오간다. 낮·밤 그림을 섞는다. 장식이라 화면낭독기에 숨긴다 | 글 아래 띠(높이 최대 16rem), 기둥 3개 | 글 아래 띠, 기둥 4개 | 글 칸이 끝난 자리부터 오른쪽 끝까지, 기둥 4개 |
| 움직임 멈춤 버튼 | "움직임 멈추기" ↔ "움직임 켜기" | 벽 오른쪽 아래 | 같음 | 같음 |
| 도구 줄 | 계열 탭 + 화면 색(밝게 · 어둡게) | 탭 줄바꿈, 색 전환은 다음 줄. 붙지 않는다 | 한 줄. 붙지 않는다 | 한 줄. 창 높이가 40rem 이상이고 줄 높이가 창 높이의 12% 이하이면 위에 붙는다 |
| 계열 묶음·카드 | 지금과 같다(카드 최소 19rem 으로 자동 배치) | 1열 | 2열 | 1024 2열, 1280·1440 3열 |
| 바닥 | 지금과 같다 | | | |

- 도구 줄은 넓고 높은 창에서만 붙인다. 좁은 폭·큰 글자에서는 붙이지 않는다(계열 탭 설계서의 이유 그대로). 큰 글자 판정은 스크립트가 한다 — 줄이 창 높이의 12%를 넘으면 붙이지 않는다. 붙을 때는 `scroll-padding-top` 으로 포커스된 요소가 줄 밑에 숨지 않게 한다(`CMP-NAV-15`).
- 첫 화면의 폭 경계(48rem·64rem·80rem)는 미디어 조건이 아니라 컨테이너 조건(`@container`)으로 잰다. 컨테이너 조건의 rem 은 지금 글자 크기를 따르므로, 글자를 키우면 쌓는 배치가 되어 글과 화면 벽이 겹치지 않는다(`TYP-04`). 화면 벽의 왼쪽 끝은 글 칸과 같은 rem 값으로 계산한다.
- 탭을 누르거나 뒤로·앞으로 가면 고른 결과가 보이게 한다(`STA-10`). 첫 카드 줄이 창 아래에서 6rem 이상 보이지 않으면 도구 줄을 맨 위로 올린다. "샘플 둘러보기"와 건너뛰기 링크도 도구 줄을 맨 위에 둔다.

## 10. 흔한 기본값과 비교

- 큰 숫자 + 작은 라벨 + 그라데이션 강조 첫 영역을 쓰지 않는다. 요약은 'A · B · C' 메타 줄이 아니라 본문 크기 문장 하나다(`SLOP-09`).
- 얇은 테두리에 넓은 그림자를 겹치지 않는다(`SHP-07`). 썸네일은 가는 테두리 하나, 화면 벽 그림은 반투명 1px 링 + 촘촘한 그림자(`SHP-03`)만 쓴다.
- 굵기는 토큰 3개만 쓴다: 보통 400 · 강조 600 · 큰 제목 700(`TYP-07`). 계열 제목 24px ÷ 카드 제목 18px = 1.33(`TYP-08`).
- 휴대폰 주소창 색(`theme-color`)은 화면 색에 맞춘다(`CLR-DARK-10`).
- 섹션마다 스크롤 등장 애니메이션을 넣지 않는다. 움직임은 화면 벽(멈춤 가능)과 사용자가 누른 직후에만 있다.
- 유리 효과·글자 그라데이션·대문자 꼬리표를 쓰지 않는다.
