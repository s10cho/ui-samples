## 7. 미확인

- 실제 키 입력과 마우스 올림: 채점 도구에 키·마우스 입력이 없어 합성 `focus()`·`click()` 으로 확인했다. 만든 쪽은 Playwright 로 탭 클릭·화면 색·멈춤 버튼을 확인했다.
- 화면 벽 30초 왕복과 화면 색 겹쳐 바꾸기는 정지 화면으로 볼 수 없어 코드로 확인했다.
- 스크립트 없음·그림 못 받음·글자 200% 는 흉내로 만든 상태다(스크립트 차단, 없는 그림 주소, `html{font-size:200%}` 주입).
