## 1. 사용자와 할 일

| 항목 | 내용 | 확인 / 가정 |
|---|---|---|
| 사용자 | 팀 공용 파일함에 문서·시안·자료를 두고 함께 쓰는 사무 담당자 | 가정 |
| 주요 작업 | ① 폴더를 오가며 파일을 찾는다 ② 파일을 올린다(끌어 놓기 또는 버튼) ③ 여러 개를 골라 옮기거나 지우고, 하나를 골라 이름을 바꾼다 | 확인 — 작업 지시 |
| 빈도 | 하루 여러 번, 한 번에 1~10개 | 가정 |
| 들어오는 길 | 옆 메뉴 "내 파일", 공유받은 폴더 주소(`?folder=`) | 가정 |
| 나가는 길 | 빵부스러기로 위 폴더, 옆 메뉴로 다른 화면 | 가정 |

## 2. 정보 우선순위

| 순위 | 정보·행동 | 이 순위인 이유 |
|---|---|---|
| 1 | 지금 폴더 위치(빵부스러기 + 폴더 이름) | 어디에 올리고 어디서 옮기는지 알아야 실수하지 않는다 |
| 2 | 항목 — 이름(폴더·파일 아이콘), 고친 날짜, 고친 사람, 크기 | 찾는 파일을 알아보는 것이 첫 일이다 |
| 3 | 고른 개수와 그 항목에 할 일(이름 바꾸기·옮기기·지우기) | 이 화면에서 끝낼 행동이다 |
| 4 | 올리는 중인 파일의 진행률·실패 | 올린 뒤 끝났는지, 실패했는지 바로 알아야 다시 시도한다 |
| 5 | 보기(목록·격자)와 정렬 | 사람마다 고정해 두고 가끔 바꾼다 |
| 6 | 저장 공간 | 거의 찼을 때만 중요하다. 그때는 배너로 끌어올린다 |

- 주 행동: 파일 올리기(페이지 머리의 강조 버튼 하나). 이름 바꾸기·옮기기·지우기는 작업 줄의 보조 버튼이다(`CMP-BTN-02`).

- 격자 카드를 새로 만드는 이유: kit 의 `ds-card` 는 화면에 붙은 묶음 상자라 고르기 상태(체크 + 바탕)와 누르는 영역 규칙이 없다. 표 행의 고른 상태 규칙(`CLR-05`)을 카드에 옮긴다.
- 올리기 카드를 새로 만드는 이유: kit 에 여러 작업의 진행률 목록이 없다. `ds-progress` 를 줄마다 쓰고, 흐름 안에 둔다(떠 있는 상자는 포커스·작업 줄과 겹친다).
- 끌어 놓기 표시: kit 에 놓을 곳 표시가 없다. DESIGN.md 「옮기기」의 "놓일 자리를 2px `line-focus` 선"을 그대로 쓴다.
- 좁은 목록: kit `ds-table--stack` 은 칸마다 이름표를 붙인 카드라 파일 한 줄이 4줄이 된다. 파일 목록은 이름이 거의 전부라 머리 행·날짜·사람·크기 열을 숨기고 이름 아래에 "크기 · 날짜" 한 줄을 둔다. 이름 칸이 행 머리(`th scope="row"`)라 숨긴 머리 행이 없어도 칸이 이름으로 읽힌다.
- 좁은 목록으로 바꾸는 경계는 화면 폭 미디어 쿼리가 아니라 결과 영역 폭 컨테이너 쿼리(40rem)다. 미디어 쿼리는 뿌리 글자 크기를 따르지 않아, 글자를 200% 로 키운 1280 화면에서 4열 표가 잘렸다. `container-type` 은 결과 영역 감싸개(`fm-results__body`)에만 준다. 그래도 넘치면(320 + 글자 200% 에서 이름 편집 중) 표 틀 안에서만 가로로 민다.
- 폴더 이름 링크는 `::after` 로 이름 칸(격자는 카드) 전체를 덮어 누르는 영역을 넓힌다. 행 높이를 늘리지 않고 마우스 24·터치 44 를 넘긴다.
- 샘플 토큰: `--file-manager-card-min`(격자 칸 최소 폭 8.5rem — 320 에서도 2열), `--file-manager-col-date`(고친 날짜 열 9.5rem — "2025년 12월 30일" + 정렬 아이콘), `--file-manager-col-by`(고친 사람 열 7rem), `--file-manager-col-size`(크기 열 6rem), `--file-manager-rename-min`(이름 편집 칸이 버튼 옆에 남는 최소 폭 8rem), `--file-manager-underline-offset`(폴더 이름 밑줄 간격 0.2em), `--file-manager-depth`(옮기기 대화상자 들여쓰기 단계, 스크립트가 줄마다 적는다). 격자 큰 아이콘은 kit `--ds-size-empty-icon`(32)을 쓴다.

## 10. 설계 메모 — 흔한 기본값과 비교

| 처음 안 | 흔한 기본값과 같은 점 | 바꾼 것 |
|---|---|---|
| 행 끝에 아이콘 버튼 4개(이름 바꾸기·옮기기·내려받기·지우기) | 행 끝 동작 여러 개(`PAT-LIST-07`), 마우스 올릴 때만 보이는 버튼 | 행 안 동작은 폴더 링크 하나. 고르기 + 작업 줄로 모은다. 하나·여러 개가 같은 길이다 |
| 지우기 전에 "정말 지우시겠어요?" 확인 | 확인 대화상자 남용 | 바로 지우고 되돌리기 배너(`CMP-BTN-13`) |
| 올리기 진행을 화면 오른쪽 아래 떠 있는 상자로 | 토스트형 떠 있는 상자 — 포커스·작업 줄과 겹친다 | 배너 아래 흐름 안 카드. 실패는 줄에 남는다 |

| 격자 보기에 큰 미리보기 그림 | 사진 카드 격자 | 그림 없이 아이콘 + 이름 + 크기·날짜. 전송량 150KB 안에 든다 |
| 저장 공간을 큰 숫자 카드로 본문 맨 위에 | 큰 숫자 + 작은 라벨 카드 | 옆 메뉴 아래 작은 진행 막대. 거의 찼을 때만 배너로 올린다 |

| 좁은 폭에서 표를 카드로 쌓기 | 칸마다 이름표를 붙인 카드 — 파일 한 개가 4줄 | 이름 아래 "크기 · 날짜" 한 줄 |
