## 8. 미확인

- 실제 키 입력·터치: 채점 도구에 없어 `focus()`·합성 `click()`·`elementFromPoint`·DOM 순서로 확인했다. 작성자는 CDP 실제 키로 이름 고치기 → Enter → 고르기 칸 포커스를 확인했다고 보고했다(검증되지 않음).
- 1회차는 768·1440·고대비·어둡게·움직임 줄이기와 그 밖의 상태를 다시 보지 않았다(변경 범위 밖).
- axe·전송량: 저장소 CI(check-pages)가 상태 6개를 데스크톱·모바일에서 돌린다(실패 0, axe 0, 128.8KB/150KB).
