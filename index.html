UI 샘플

디자인 시스템과 디자인 패턴을 분석하려고 만든 화면 샘플입니다.정적 웹 페이지라 서버 없이 브라우저에서 바로 열립니다. 모든 샘플은 화면 폭에 맞춰 바뀝니다.

샘플 22개가 모두 독립 검수에 합격했고, 평균 점수는 90.4점입니다.

업무 화면
