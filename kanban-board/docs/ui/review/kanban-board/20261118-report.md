## 6. 미확인

- 실제 Tab 순서·Enter·Space: 채점 도구에 키 입력이 없어 합성 이벤트로 확인했다(메뉴 ↓·↑↓·Esc, 활성화는 합성 click). 작성자는 CDP 실제 키로 카드를 옮겼다고 보고했다(검증되지 않음).
- 터치 길게 누르기 끌기: 마우스형 PointerEvent 로만 확인했다(놓기, 가득 찬 열 막힘, Esc 취소).
- axe·움직임 줄이기 화면·375 어둡게·스크롤 상태 포커스 가림: 채점자는 보지 못했다. 저장소 CI(check-pages)가 상태 6개를 데스크톱·모바일에서 돌린다(실패 0, axe 0).
