- 처음 시점 맞춤(3-2절)은 장면에서 **버튼이 없는 빈 영역**을 기준으로 한다. 빈 영역 = 장면 − 정보 패널(넓은 폭) − 장면 토글 묶음의 실제 높이 − 층 버튼·시점 버튼 묶음의 실제 폭·높이. 글자 200% 에서 묶음이 커지면 빈 영역도 그만큼 줄어든다.

### 3-1. 장면 구성

모양은 저폴리(면이 보이는 단순한 입체)와 납작한 음영으로 만든다. 건축 모형처럼 보이게 한다. 모델·텍스처 파일은 쓰지 않고 모두 코드로 만든다. 실제 박물관을 본뜨지 않은 가상의 건물이다.

좌표: x 는 동쪽(화면 오른쪽), z 는 남쪽(입구 쪽)이 +. 층 바닥은 가로 16 × 세로 10. 층마다 뒤쪽(북쪽) 띠에 계단(서쪽)·엘리베이터(가운데)·화장실(동쪽)이 같은 자리에 있고, 앞쪽에 전시실이 있다.

| 입구 | 1층 남쪽 벽의 문. 문 바로 바깥 마당 길 위에 진한 원판과 기둥 하나(구현 때 바꿈 — 문 안쪽에 두면 쌓아 보기에서 벽에 가려 표지가 숨었다) | "지금 여기" |
| 마당 | 1층 아래 넓은 바닥판. 그 밖은 바탕색 | 없음 |

- 그림자를 계산하지 않는다. 실내 모형이라 면 밝기 차이(납작한 음영)만으로 깊이가 읽힌다. 그래서 높은 품질과 낮은 품질의 장면 모양이 같다(4-2절).
- 바탕은 단색이다. 3D의 땅(마당 밖)과 하늘이 모두 바탕색(`scene.bg`)이라 포스터 가장자리가 페이지 바탕과 이어진다.

### 3-2. 보는 방식·층 고르기·시점

| 항목 | 값 |
|---|---|
| 펼쳐 보기(기본) | 층 사이를 6.5 띄운다. 바깥벽은 낮게(0.9) 잘라 방 안이 보인다 |
| 쌓아 보기 | 층 사이가 실제 높이(2.6)다. 바깥벽이 다 올라와(2.3) 건물 모양이 보인다. 지붕 없는 4층만 안이 보인다 |
| 층을 고르면 | 그 층보다 위층은 위로 비켜 올라가고(펼쳐 보기 +8, 쌓아 보기 +14 — 구현 때 늘림: +9 에서는 흐려진 위층이 고른 층의 뒤쪽 시설을 가렸다) 흐려진다. 아래층은 제자리에서 흐려진다. 고른 층은 바깥벽을 낮게 잘라 안을 보인다. 흐려짐 = 바탕색 쪽으로 75% 섞는다(투명하게 하지 않는다 — 겹친 면이 깨져 보이지 않게) |
| 전시실을 고르면 | 층을 고른 상태 그대로 두고 그 전시실 바닥을 강조한다. 시점이 그 전시실로 간다 |
| 처음 시점 | 남남동쪽(방위 30°) 위에서 내려본다(내려보는 각 30°). 펼친 4개 층과 마당이 빈 영역에 다 들어온다. 맞춤은 건물을 감싼 원기둥(반지름 9.6)으로 한다 — 자동 회전 중 어느 방위에서도 건물과 표지가 빈 영역 밖(토글·버튼 아래)으로 나가지 않는다 |
| 카메라 위치 | 처음 시점의 카메라 위치·거리는 화면 크기와 상관없이 하나다(중심점에서 70). 화면 크기에 맞추는 일은 시야 배율(`zoom`)과 시야 이동(`setViewOffset`)으로만 한다. 그래서 포스터가 첫 프레임과 원근까지 같다(바탕 샘플 검수 지적 STA-03) |
| 층 시점 | 중심점을 고른 층 가운데로, 방위 20°, 내려보는 각 55°. 거리는 그 층 바닥 전체가 빈 영역의 92% 안에 들어오게 계산한다 |
| 전시실 시점 | 중심점을 전시실 가운데로, 방위 20°, 내려보는 각 50°. 거리는 전시실이 빈 영역 높이의 절반, 폭의 70% 안에 들어오게 계산한다 |
| 각도 제한 | 내려보는 각 15°~75° |
| 거리 제한 | 가장 가까이: 가로 5 짜리 전시실 하나가 빈 영역 높이의 절반을 넘지 않는다(이웃 방과 벽이 함께 보여 어디인지 안다). 가장 멀리: 처음 시점 거리의 1.5배 |
| 중심점 제한 | 사용자가 중심점을 옮기는 조작은 없다. 중심점은 처음 시점·층 시점·전시실 시점 사이에서만 움직인다 |
| 자동 회전 | 처음 들어왔을 때 층을 고르기 전에만 아주 느리게(한 바퀴 약 90초). 사용자가 한 번 조작하면(고르기 포함) 끄고 다시 켜지 않는다 |
| 인트로 | 없음. 첫 프레임부터 처음 시점이다 |
| 첫 프레임의 장면 시각 | 포스터를 찍은 장면 시각과 같다. 엘리베이터 칸과 관람객 점 위치가 튀지 않는다 |
| 주소로 들어왔을 때 | 첫 프레임은 늘 처음 시점(펼쳐 보기, 고르기 전)이다. 3D가 준비되면 주소의 보는 방식·층·전시실로 시점이 옮겨 간다. 포스터와 첫 프레임이 늘 같다 |

### 3-3. 표지

| 표지 | 언제 보이나 | 누르면 | 우선순위(겹치면 낮은 것을 숨긴다) |
|---|---|---|---|
| 고른 전시실·층 표지 | 고른 것 | 아무 일 없음(이미 고른 것) | 1 — 버튼과 겹치면 위아래로 비킨다 |
| 지금 여기 | 처음 시점, 1층을 골랐을 때 | 1층을 고른다 | 2 — 알약은 입구 기둥 밑동 아래(마당 쪽)에 먼저 단다. 그 자리가 장면 끝·버튼에 막히면 기둥 머리 위에 단다(0회차 검수 반영 — 위에 달면 회전 중 2층 바닥 위에 놓여 2층으로 읽혔다) |

- 층 표지는 층 바닥의 네 모서리 가운데 카메라에 가장 가까운 모서리에 붙인다. 회전해도 앞쪽에 남아 위층에 가려지지 않는다.
- 표지는 모두 `aria-hidden="true"`, `tabindex="-1"` 이다. 키보드와 화면낭독기는 목록과 층 버튼으로 같은 일을 한다.
- 편의시설 아이콘은 흰 원(보이는 크기 28) 안의 선 아이콘이다. 누르는 대상이 아니라 그림이다.

## 6. 상호작용

| 동작 | 마우스·터치 | 키보드 | 결과 |
|---|---|---|---|
| 층 고르기 | 층 행, 장면의 층 버튼, 층 표지 | Tab 으로 층 행·층 버튼에 가서 Enter·Space | 층 시점으로 600ms 이동. 위층이 비켜 오르고 흐려진다. 그 층의 전시실 행이 펼쳐진다. 상태 알림. 포커스는 누른 버튼에 그대로 |
| 전시실 고르기 | 전시실 행, 전시실 표지 | 펼쳐진 전시실 행에서 Enter·Space | 전시실 시점으로 이동. 바닥 강조. 상세 갱신. 상태 알림 |
| 한 단계 위로 | — | Esc. 툴팁이 보이면 첫 Esc 는 툴팁만 닫는다 | 전시실 → 층 → 고르기 전. 고르기 전이면 처음 시점으로 |
| 처음 시점으로 | "처음 시점으로 돌아가기" 버튼 | 같은 버튼 | 고르기를 모두 풀고 처음 시점으로(보는 방식은 그대로) |
| 펼쳐 보기 ↔ 쌓아 보기 | 토글 버튼 | Tab + Enter·Space | 층이 600ms 에 옮겨진다(움직임 줄이기면 즉시). 고른 층·전시실은 그대로. 시점은 지금 고른 것에 맞춰 다시 맞춘다 |
| 편의시설 보기·숨기기 | 목록 머리의 토글 버튼 | Tab + Enter·Space | 아이콘이 바로 보이거나 숨는다. 라벨이 바뀐다 |
| 건물 돌리기 · 기울이기 · 가까이·멀리 | 바탕 샘플과 같다 | 바탕 샘플과 같다 | 바탕 샘플과 같다. 자동 회전이 꺼진다 |
| 이동 중 다른 입력 | 끌기·휠·탭 | 다른 버튼 | 진행 중인 시점 이동을 바로 취소한다 |

- 조작 안내는 입력 방법에 맞춰 3가지 중 하나만 보인다(바탕 샘플과 같다). 3D가 준비된 뒤에만 보인다.
- 포커스 순서: 건너뛰기 링크 → 움직임 토글 → 보는 방식 토글 → 층 버튼 4개(4층→1층) → 시점 버튼 5개 → 배너(있으면) → 편의시설 토글 → 층·전시실 목록 → 상세.
- 단축키: Esc 만 둔다. 글자 1개 단축키는 두지 않는다.
- 장면 `<canvas>` 에는 `role="img"` 와 대체 텍스트. ready 에서만 캔버스를 접근성 트리에 두고, 그 밖에서는 포스터를 둔다(바탕 샘플 공통 수정 유지).
- 배너를 지울 때 포커스가 배너 안에 있었으면 장면 토글 가운데 보이는 첫 버튼으로, 없으면 목록 머리(`#floors`)로 옮긴다(바탕 샘플 공통 수정 유지).
- live 영역은 비어 있어도 렌더링해 두고 화면에서만 숨긴다(바탕 샘플 공통 수정 유지).

### 6-1. 주소와 뒤로 가기

| 지금 | 한 일 | 주소 | 방문 기록 |
|---|---|---|---|
| 고르기 전 | 층을 고른다 | `?floor=2` | 새로 하나 쌓는다(`pushState`) |
| 층 | 그 층의 전시실을 고른다 | `?floor=2&room=pottery` | 새로 하나 쌓는다 |
| 층 | 다른 층을 고른다 | `?floor=3` | 지금 기록을 바꾼다(`replaceState`) — 같은 단계 안의 이동이다 |

| 전시실 | 다른 층(층 버튼·층 행) | `?floor=3` | 한 단계 위로 간 뒤 바꾼다 |
| 어디서나 | Esc · 처음 시점 버튼(위로 가기) | 위 단계의 주소 | 이 화면이 쌓은 기록이 있으면 그만큼 되돌아간다(`history.back`). 쌓은 기록이 없으면(주소로 바로 들어옴) 지금 기록을 바꾼다 |
| 어디서나 | 브라우저 뒤로 가기 | 이전 기록 | 한 단계 위로(전시실 → 층 → 고르기 전). 고르기 전에서 한 번 더 누르면 이 페이지를 떠난다 |

- 보는 방식(`view`)·편의시설(`facilities`)은 기록을 쌓지 않고 지금 주소만 바꾼다. 뒤로 가기로 보는 방식이 바뀌지 않는다.
- `file://` 로 연 페이지는 주소를 바꿀 수 없다(브라우저 제한). 그때는 Esc·버튼으로만 오간다.

해당 없음 — 새 샘플이다. 바탕 샘플의 화면을 바꾸지 않는다. 바탕 샘플에서 가져온 동작(부팅 두 갈래·안전장치·포스터 배치·쿼리 파라미터·접근성 처리·공통 수정 4건)은 모두 유지한다.

## 10. 설계 메모 — 흔한 기본값과 비교

| 처음 안 | 흔한 기본값과 같은 점 | 바꾼 것 |
|---|---|---|
| 층마다 카드 1장, 카드 안에 전시실 칩 | 층별 안내 페이지의 흔한 모양이다. 카드 격자(`SLOP-06`) | 층 행 아래 전시실 행이 펼쳐지는 목록 하나. 고른 층만 펼친다 |
| 층 고르기를 탭(1층·2층·3층·4층 가로 탭) | 매장 지도 앱의 흔한 모양이다. 탭은 3D 처럼 위아래가 없어 층의 높낮이가 안 읽힌다 | 장면 안 층 버튼을 위층이 위인 세로 묶음으로. 목록도 위층부터 |
| 편의시설을 색 점 + 범례로 | 색만으로 종류를 나눠 `STA-13` 위반 위험 | 모양이 다른 선 아이콘 4개 + 이름 풀이 |
| 고르지 않은 층을 반투명하게 | 3D 층 안내의 흔한 연출. 투명한 면이 겹치면 그리는 순서가 틀려 깨져 보인다 | 바탕색 쪽으로 섞어 흐리게(불투명). 위층은 위로 비켜 고른 층을 가리지 않는다 |
| "지금 여기"를 깜빡이는 빨간 점 | 실내 지도의 흔한 표시. 깜빡이는 점(`SLOP-11`)이고 빨강은 오류로 읽힌다 | 깜빡이지 않는 진한 알약 + 흰 점. 장면에는 진한 원판·기둥 |
| 강조색으로 층마다 다른 색 | 층 구분의 흔한 방법. 주색이 여러 개가 된다(`SLOP-UI-01`) | 층은 모두 같은 색. 강조색은 고른 것 하나에만 |
| 처음 들어오면 1층을 골라 둔 상태 | 실내 지도 앱의 흔한 기본값. 위층에 무엇이 있는지 첫눈에 안 보인다 | 4개 층을 펼친 전체 모습에서 시작. "지금 여기"로 1층 입구를 알린다 |
| 처음 시점을 화면 크기마다 카메라 거리로 맞춤 | 바탕 샘플의 방식. 포스터와 원근이 달라졌다(검수 지적) | 카메라 위치는 하나로 두고 시야 배율·시야 이동으로만 맞춘다 |

- `MOT-01` 예외: 시점 이동과 층 옮기기는 600ms 로 한다. 바탕 샘플과 같은 이유다(큰 움직임을 400ms 에 끝내면 너무 빨라 어지럽다 — 추정). 감속 곡선, 입력이 오면 취소, 움직임 줄이기면 즉시 전환.
- 위키 공백: 화면 유형 표에 소비자용 공간 안내(지도·층 안내) 유형이 없다. 이 설계서는 목록 + 상세로 옮겨 적었다.

바탕 샘플 검수에서 남은 지적을 이 설계에서 처리한 방법:

| 지적 | 이 설계의 처리 | 적은 곳 |
|---|---|---|
| 포스터와 첫 프레임의 품질 단계가 다르다(city-night 4절 1) | 품질 단계가 장면 모양을 바꾸지 않는다(해상도만). 포스터도 그 폭의 기본 품질로 찍는다 | 4-2절 |
| 포스터 카메라를 물려 찍어 원근이 다르다(ski-mountain 4절 1) | 카메라 위치 하나, 시야 배율·시야 이동으로만 맞춤 | 3-2절, 4절 |
| 움직이는 물체 위치가 다르다 | 첫 프레임 장면 시각 = 포스터 장면 시각 | 3-2절 |
| "가까이 보기"가 설계서 최소 거리보다 가깝다(ski-mountain 4절 2) | 최소 거리를 빈 영역 높이로 계산해 늘 같은 기준을 지킨다 | 3-2절 |
| 글자 200% 에서 토글이 첫 프레임 대상을 가린다(ski-mountain 4절 3) | 처음 시점을 버튼 묶음의 실제 크기를 뺀 빈 영역에 맞춘다 | 3절 끝 |
| 자동 회전 중 높은 명소 표지가 토글 아래로 오래 숨는다(city-night 4절 2) | 원기둥으로 맞춰 어느 방위에서도 건물이 빈 영역 안. 층 표지는 가까운 모서리에 붙인다 | 3-2절, 3-3절 |
| 공통 4건(로딩 중 조작 안내, 배너 뒤 포커스, live 영역, 멈춤 때 대체 텍스트) | 바탕 샘플의 수정을 그대로 유지 | 5절, 6절 |
