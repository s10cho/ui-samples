## 1. 사용자와 할 일

| 항목 | 내용 | 확인 / 가정 |
|---|---|---|
| 사용자 | 고객 상담팀 상담원(정유진). 상담 배정·메모 언급·고객 답장·아침 요약·보안 알림을 받는다. 상담 인박스·설정 샘플과 같은 가상 팀이다 | 확인 — 작업 지시(알림 목록), 가정(팀·직무) |
| 주요 작업 | ① 읽지 않은 알림을 훑고 대상으로 간다 ② 하나씩 또는 모두 읽음으로 표시한다 ③ 필요 없는 종류의 알림을 끄거나 알림 설정으로 간다 | 확인 — 작업 지시 |
| 빈도 | 근무 중 수시로 연다. 한 번에 5~10건을 훑는다 | 가정 |
| 들어오는 길 | 옆 메뉴의 "알림", 공유받은 주소(`?open=<알림 id>`) | 가정 |
| 나가는 길 | 알림 대상(상담 인박스의 대화, 보안 설정)으로 간다. 옆 메뉴로 다른 화면에 간다 | 가정 |

## 2. 정보 우선순위

| 순위 | 정보·행동 | 이 순위인 이유 |
|---|---|---|
| 1 | 읽지 않은 알림 — 누가, 무엇을, 언제 | 상담원의 첫 판단은 "새로 온 일이 무엇인가"다 |
| 2 | 알림 대상으로 가기(알림을 누르면 옆 패널에 대상 요약 + 대상 화면 링크) | 알림은 대상으로 가는 길이다 |
| 3 | 읽음 표시(하나·모두) | 다 본 알림을 치워 다음 알림이 보이게 한다 |
| 4 | 보기(읽지 않음 · 전체)와 종류 거르기(배정·언급·답장·요약·보안) | 많을 때 범위를 줄인다(`PAT-CHAT-06`) |
| 5 | 새 알림 도착 | 보는 중에 순서를 흔들지 않고 알린다 |
| 6 | 알림 끄기·알림 설정 | 자주 하지 않지만 알림이 너무 많을 때 필요하다 |

- 주 행동: 영역마다 하나(`PAT-ARC-02`). 목록 영역은 강조색 채움 버튼을 두지 않는다(알림을 누르는 것이 주 행동이다). 옆 패널의 주 행동은 "대상 열기"(강조색 채움 1개).

## 3. 영역 구성

kit 앱 틀(`.ds-app`) 안에 머리줄 · 옆 메뉴 · 본문 · 옆 패널을 둔다. 본문 폭은 알림 줄이 너무 길어지지 않게 52rem(832px)까지만 쓴다.

| 영역 | 위치 | 담는 것 | 컴포넌트 | 좁은 폭(375) | 중간 폭(768) | 넓은 폭(1280 이상) |
|---|---|---|---|---|---|---|
| 건너뛰기 링크 | 맨 앞 | "알림 목록으로 건너뛰기" | `ds-skip-link` | 같음 | 같음 | 같음 |
| 머리줄 | 위 | 메뉴 버튼, "UI 샘플", 가상 데이터 안내, 화면 밝기 | `ds-topbar` · `ds-sample-note` · `ds-segmented` | 메뉴 버튼 보임, 밝기는 아이콘만 | 메뉴 버튼 보임 | 메뉴 버튼 숨김 |
| 옆 메뉴 | 왼쪽 | 작업 공간(알림 — 지금 화면 + 읽지 않은 수, 상담 인박스, 설정), 이 저장소(샘플 목록, 부품 모음) | `ds-sidenav` | 서랍 | 서랍 | 왼쪽 240 |
| 페이지 머리 | 본문 위 | 제목 "알림", "모두 읽음 표시", "알림 설정"(설정 샘플의 알림 탭 링크) | `ds-page__head` · `ds-btn` | 제목 아래로 버튼 줄이 내려감 | 한 줄 | 한 줄 |
| 배너 자리 | 페이지 머리 아래 | 오프라인 · 모두 읽음 실패 · 알림 끈 뒤 되돌리기 | `ds-banner-slot` · `DS.banner` | 같음 | 같음 | 같음 |
| 도구 줄 | 목록 위 | 보기(읽지 않음 N · 전체 N), 종류 칩 5개(개수 · 끈 종류는 "꺼짐"), "거르기 지우기" | `ds-segmented` · `ds-chip[aria-pressed]` · `ds-btn--ghost` | 보기 한 줄, 칩은 여러 줄로 감김 | 보기와 칩이 한두 줄 | 한 줄 |
| 새 알림 자리 | 도구 줄 아래, 목록 위 | "새 알림 2건 보기"(왔을 때만) | `ds-btn--sm` | 같음 | 같음 | 같음 |
| 알림 목록 | 본문 | 날짜 묶음(오늘 · 어제 · 이번 주 · 이전) 제목 + 알림 줄 | 묶음 제목 h2 + `ul`, 알림 줄은 샘플 부품(아래 4절) | 줄 안 동작 버튼이 시각 줄 오른쪽으로 내려감(글이 전체 폭을 씀) | 동작 버튼이 오른쪽 열 | 같음 |
| 빈·오류 자리 | 목록 자리 | 읽지 않은 알림 없음 · 전체 없음 · 거르기 결과 없음 · 불러오기 오류 | `ds-empty` · `ds-empty--error` | 같음 | 같음 | 같음 |
| 옆 패널 | 오른쪽 | 알림 대상: 대상 이름, 알림 문장, 인용, 종류·보낸 사람·받은 시각(정확한 시각), "대상 열기" 링크 | `ds-panel` · `ds-dl` | 전체 폭으로 덮음(뒤 `inert`) | 360 으로 덮음 | 360 으로 붙음(본문이 40rem 보다 좁으면 덮음) |

## 4. 컴포넌트

| 컴포넌트 | 기존 / 새로 | 변형 | 쓰는 토큰 | 관련 규칙 |
|---|---|---|---|---|
| 앱 틀·머리줄·옆 메뉴·옆 패널 | 기존 kit | 패널 `?open=<id>` | kit 그대로 | `CMP-TABLE-05` |
| 보기 묶음 버튼 | 기존 `ds-segmented` | `data-url-key="view"` | kit | `PAT-LIST-11` |
| 종류 칩 | 기존 `ds-chip` | `aria-pressed`, 켜지면 체크 | kit | `CMP-SEL-09` `PAT-LIST-03` |
| 버튼 | 기존 `ds-btn` | 기본 · `--ghost` · `--icon` · `--sm` · 패널 `--primary` | kit | `CMP-BTN-04` |
| 메뉴(알림마다 "더 보기") | 기존 `ds-menu` | 끌 수 없는 종류는 `ds-menu__item--detail` + `aria-disabled` | kit | `PAT-LIST-07` |
| 배너 | 기존 `DS.banner` | `--warning`(오프라인) · `--danger`(모두 읽음 실패) · `--info`(알림 끔 + 되돌리기) | kit | `STA-09` |
| 빈 상태 | 기존 `ds-empty` | 기본 · `--error` | kit | `WRT-MSG-04` |
| 스켈레톤 | 기존 `DS.skeleton`(복제) | 머리 동작 · 도구 줄 · 목록 · 패널 몸통 | kit | `STA-03` `CMP-FB-09` |
| 설명 목록 | 기존 `ds-dl` | 패널 안 | kit | — |
| 아바타 | 기존 `ds-avatar` | 사람은 이름 두 글자, 요약·보안은 아이콘 | kit | `PAT-CHAT-06` |
| 알림 줄 | **새로**(샘플 `nc-item`) | 읽지 않음(점 + 굵은 문장 + 화면낭독기용 "읽지 않음") · 읽음 · 연 알림(`aria-current`) | `--ds-color-*` · `--ds-space-*` | `CMP-LIST-13` `CMP-SEL-04` |

- 알림 줄을 새로 만드는 이유: `ds-list__row` 는 줄 전체가 링크나 버튼 하나다. 알림 줄은 대상으로 가는 링크와 줄 안 동작 2개(읽음 표시 · 더 보기)를 함께 둬야 한다. 링크 안에 버튼을 넣을 수 없어, 링크는 문장에 두고 `::after` 로 줄 전체를 누르는 영역으로 넓힌다. 동작 버튼은 그 위에 올린다.
- 샘플 토큰: `--notification-center-feed-max`(52rem, 알림 줄 길이 제한 — kit 의 읽는 글 640 은 도구 줄이 너무 좁아지고, 콘텐츠 1280 은 문장이 너무 길다), `--notification-center-dot`(읽지 않음 점 8px = `--ds-space-2`), `--notification-center-actions-w`(줄 안 동작 칸 = 아이콘 버튼 2개 + 간격. 읽은 줄도 같은 폭이라 글 오른쪽 끝이 맞는다).
- 줄 배치는 목록 폭(컨테이너 쿼리 `nc-feed`)으로 세 단계다. 36rem 이상: 점 · 아바타 · 글 · 동작 칸. 36rem 미만: 글이 전체 폭, 동작은 종류·시각 줄 오른쪽. 18rem 미만(320 + 글자 200% 등): 아바타(꾸밈)를 빼고 글 · 종류와 시각 · 동작을 한 줄씩. 경계는 컨테이너 조건이라 변수를 못 써 CSS 에 숫자로 적는다.
- 인용은 줄 수를 자르지 않는다(글자 200% 에서도 다 읽힌다). 데이터에서 한 문장으로 짧게 쓴다.

## 5. 상태

| 상태 | 언제 | 보이는 것 | 문구 | 사용자 행동 | 확인 방법 |
|---|---|---|---|---|---|
| 초기 로딩 | 처음 열 때 1.2초 흉내(1초를 넘어 스켈레톤을 보인다, `STA-01`). `?state=loading` 은 끝나지 않는다 | `DS.loadingTimer` 로 0.3초 뒤 복제 스켈레톤: 머리 동작 버튼 자리, 도구 줄(보기·칩), 목록(묶음 제목 + 알림 줄), 주소에 `open` 이 있으면 패널 몸통까지. 실제 내용(가상 데이터)을 먼저 그린 뒤 복제하고, 0.3초 전까지는 자리 크기를 둔 채 내용만 숨긴다(`data-nc-pending`). 제목 "알림"·패널 제목·패널 칸 이름은 고정 글이라 그대로(`data-ds-skeleton-keep`). 읽지 않음 점과 연 줄의 고른 색은 내용이 온 뒤에. 옆 메뉴 개수도 끝난 뒤에. 목록 `aria-busy="true"` | live: "알림을 불러오는 중이에요"(끝나면 비운다) | 없음 | 2026-11-18 측정: 스켈레톤 → 내용 위치 차 0px — 1280(패널 붙음 포함), 768(패널 덮음), 375 터치 |
| 부분 로딩 | 불러오기 오류에서 "다시 불러오기"(1.2초) · 오프라인에서 "다시 연결"(1.2초) | 다시 불러오기: `DS.loadingTimer` 로 0.3초 뒤 같은 스켈레톤, 끝나면 첫 알림에 포커스(결과 문장은 따로 보내지 않는다 — 한 번 불러오기에 한 문장). 다시 연결: 배너 버튼만 `DS.busy` "연결 중…" | 같음 / "다시 연결했어요" | 기다린다 | 측정: 100ms 스켈레톤 0개, 400ms 3개 |
| 빈 화면(처음 사용) | 받은 알림이 하나도 없을 때(`?state=zero`) | 목록 자리 빈 상태(종 아이콘). 도구 줄의 칩은 숨긴다(거를 것이 없다). 도움말 링크는 두지 않는다(DESIGN.md `STA-07` 예외) | "아직 받은 알림이 없어요" / "상담이 배정되거나 누가 나를 언급하면 여기에 모여요." / "알림 설정 열기" | 링크 | `?state=zero` |
| 빈 화면(읽지 않은 알림 없음) | 읽지 않음 보기에 알림이 없을 때(`?state=caught-up`, 또는 모두 읽음 표시 뒤) | 목록 자리 빈 상태(완료 아이콘) | "읽지 않은 알림이 없어요" / "새 알림이 오면 여기에 보여요." / "전체 알림 보기" | 버튼(보기를 전체로) | `?state=caught-up` |
| 빈 화면(거르기 결과 없음) | 고른 종류에 맞는 알림이 없을 때 | 목록 자리 빈 상태 + 거르기를 푸는 버튼(`STA-08`) | "고른 종류의 알림이 없어요" / "다른 종류를 고르거나 거르기를 지우면 더 많은 알림이 보여요." / "거르기 지우기" · (읽지 않음 보기면) "전체 알림 보기" | 버튼 | `?view=unread&kind=security` |
| 불러오기 오류 | 목록을 받지 못했을 때(`?state=error`, 다시 불러오기는 성공) | 목록 자리에 `ds-empty--error`(오류 아이콘 + 제목 + 설명 + 다시 불러오기). 배너에 두지 않는다(DESIGN.md). 개수는 비운다. 주소의 `open` 은 지운다 | "알림을 불러오지 못했어요" / "연결이 잠시 끊겼어요. 다시 불러오면 이어서 볼 수 있어요." / "다시 불러오기". live(assertive): "알림을 불러오지 못했어요" | 다시 불러오기 → 첫 알림에 포커스 | `?state=error` |
| 저장·전송 오류 | "모두 읽음 표시"가 실패할 때(`?state=markall-fail` — 첫 시도만 실패) | 아래 "낙관적 업데이트 실패"와 같다 | — | — | — |
| 권한 없음 | 해당 없음 — 알림은 받는 사람 자신의 것이다. 권한 관리 샘플이 따로 다룬다 | — | — | — | — |
| 오프라인 | 연결이 끊겼을 때(`?state=offline`, 또는 브라우저 `offline` 이벤트) | 배너 자리에 경고 배너(닫기 없음 — 상태가 이어지는 동안 남는다). 목록은 마지막으로 받은 그대로 쓴다. 읽음 표시는 화면에 바로 남기고 연결되면 보낸다. 새 알림은 오지 않는다 | "연결이 끊겼어요" / "새 알림을 받지 못하고 있어요. 읽음 표시는 연결되면 보내요." / "다시 연결" | 다시 연결 → 배너가 사라지고 포커스는 "모두 읽음 표시" | `?state=offline` |

## 6. 상호작용

| 동작 | 마우스·터치 | 키보드 | 결과 |
|---|---|---|---|
| 보기 바꾸기 | 묶음 버튼 | ←→ | 목록을 다시 그림, 주소 `?view=all`, live "알림 18건이 보여요" |
| 종류 거르기 | 칩 누르기(여러 개) | Tab · Space/Enter | 켜면 체크, 주소 `?kind=assign,mention`, live "알림 N건이 보여요". "거르기 지우기"를 누르면 첫 칩으로 포커스 |
| 알림 열기 | 줄 아무 곳(동작 버튼 밖) | 링크에서 Enter | 읽음으로 바꾸고 옆 패널에 대상. 주소 `?open=n01`. 연 줄은 고른 색 + `aria-current`. 덮는 폭은 포커스가 패널 제목 |
| 패널 닫기 | 닫기 버튼 · 가림막 | Esc | 연 알림 링크로 포커스(그 줄을 다시 그렸으면 같은 id 의 새 링크로) |
| 대상 열기 | 패널의 "상담 인박스에서 열기" 등 | Enter | 상담 인박스 샘플의 그 대화(`?c=`), 또는 설정 샘플의 탭으로 간다 |
| 하나 읽음 | 줄의 확인 아이콘 버튼(읽지 않은 줄만) | Enter | 읽음, 포커스는 같은 줄 "더 보기", live "읽음으로 표시했어요" |
| 읽지 않음으로 | "더 보기" → "읽지 않음으로 표시" | 메뉴 ↑↓ Enter | 점이 돌아오고 포커스는 "더 보기" |
| 이 종류 끄기 | "더 보기" → "‘언급’ 알림 끄기" | 같음 | 칩에 "꺼짐", 정보 배너(되돌리기 · 알림 설정 열기). 포커스는 "더 보기" |
| 모두 읽음 | "모두 읽음 표시"(거르는 중이면 "고른 종류 읽음 표시") | Enter | 보이는 범위의 읽지 않은 알림을 바로 읽음으로. 읽지 않음 보기면 성공 뒤 빈 상태. 포커스는 버튼에 남음 |
| 새 알림 보기 | "새 알림 2건 보기" | Enter | 목록 맨 위에 넣고 첫 새 알림 링크에 포커스. 거르기 때문에 안 보이면 버튼 자리에 남은 도구 줄 보기 묶음으로 포커스 + 알림 |
| 알림 사이 옮기기 | — | 알림 링크에서 ↑↓ | 앞·뒤 알림 링크로 포커스(묶음을 넘어 이어진다) |

- 포커스 순서: 건너뛰기 링크 → 머리줄 → (옆 메뉴) → 머리 동작(모두 읽음 표시 · 알림 설정) → 배너 → 보기 → 칩 → 거르기 지우기 → 새 알림 보기 → 알림 줄(링크 → 읽음 표시 → 더 보기) → 옆 패널.
- 단축키: 알림 링크에서 ↑↓ 만 둔다. 한 글자 단축키는 두지 않는다(WCAG 2.1.4).

| 옆 패널이 글자 크기 변화(창 크기는 그대로)에 붙임을 다시 재지 않음 | 본문 `ResizeObserver` 가 뿌리 글자 크기 변화를 보면 `resize` 이벤트를 보낸다 | `DS.panel` 이 뿌리 글자 크기 변화에도 `syncPanel` |
| 끝난 불러오기의 "불러오는 중" 문장이 7초 남음 | 끝나면 `#ds-live` 글을 비운다 | `DS.announce.clear()` 또는 `DS.loadingTimer` 가 끝날 때 비우기 |
| 배너 동작에 링크가 없음 | `DS.banner.show` 뒤 `.ds-banner__actions` 에 `<a class="ds-btn ds-btn--sm">` 를 붙인다 | 배너 동작 `{ label, href }` |
