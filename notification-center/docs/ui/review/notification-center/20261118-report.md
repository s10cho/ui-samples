## 5. 미확인

- 실제 키 입력: 채점 도구에 키 입력이 없어 합성 이벤트로 확인했다. 작성자는 CDP 실제 키 입력(Tab·화살표·Space·Enter·Esc)으로 확인했다고 보고했다(검증되지 않음).
- 움직임 줄이기의 스켈레톤 멈춤, 글자 크기만 바뀔 때 패널 다시 재기: 코드로만 확인했다.
- axe·전송량: 채점자는 돌리지 못했다. 저장소 CI(check-pages)가 상태 6개를 데스크톱·모바일에서 돌린다(작성자 실행: 실패 0, axe 0, 112.3KB/150KB).
