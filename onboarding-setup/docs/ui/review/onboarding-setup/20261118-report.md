## 7. 미확인

- 실제 키보드: 채점 도구에 키 입력이 없어 합성 `click()` 으로 확인했다. 작성자는 CDP 실제 키 입력(Tab·Shift+Tab·Enter·End)으로 1단계 → 4단계 → 첫 화면을 확인했다고 보고했다(검증되지 않음).
- 고대비 실제 팔레트: 헤드리스 에뮬레이션은 media 만 켠다. 모양 구분(점선 원 + 빼기 / 실선 원 + 체크)은 확인했다.
- 진행 막대 `aria-valuetext`: 코드는 값을 넣는다. 스냅숏 도구 표시가 비어 있어 가리지 못했다.
- axe·전송량: 저장소 CI(check-pages)가 상태 6개를 데스크톱·모바일에서 돌린다(작성자 실행: 실패 0, axe 0, 109.7KB/150KB).
