## 7. 미확인

- 375 + 글자 200% 에서 아래 줄이 화면을 덮는 비율: 2회차 측정이 실패했다. 작성자 수치(줄 261 / 여백 277)로는 줄이 화면의 약 32% 를 덮는다(추정).
