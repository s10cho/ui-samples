## 7. 미확인

- 실제 터치·Tab 키: 채점 도구에 없어 합성 `focus()`·`click()` 과 `elementFromPoint` 로 확인했다. 작성자는 Playwright 실제 키 입력으로 흐름을 확인했다고 보고했다(검증되지 않음).
- 320 모바일에서 아래 끝 칸 이동량, 짧은 줄의 어둡게·고대비 모습, 전체 줄 저장 버튼에 키보드 포커스가 갈 때 머리줄 가림: 2회차에 보지 못했다.
- axe·전송량: 저장소 CI(check-pages)가 상태 6개를 데스크톱·모바일에서 돌린다(작성자 실행: 실패 0, axe 0, 126.0KB/150KB).
