## 7. 미확인

- 실제 키 입력: 채점 도구에 키 입력이 없어 합성 이벤트로 확인했다. 작성자는 CDP 실제 키로 1280·375 주요 흐름(결과 ↑↓, 미리 보기 Enter·Esc, 더 보기)을 확인했다고 보고했다(검증되지 않음).
- 1회차는 320·375 화면을 숫자 측정으로만 판정했다(스크린샷 시간 초과).
- 어둡게에서 `mark`·아바타는 1회차에 다시 보지 않았다.
- axe·전송량: 저장소 CI(check-pages)가 상태 6개를 데스크톱·모바일에서 돌린다(작성자 실행: 실패 0, axe 0, 132.3KB/150KB). `?q=정살` 처럼 주소로 넣은 글자가 글꼴 조각에 없으면 다이나믹 서브셋을 받아 더 커진다(판정 대상 아님).
