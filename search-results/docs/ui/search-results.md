## 1. 사용자와 할 일

| 항목 | 내용 | 확인 / 가정 |
|---|---|---|
| 사용자 | 사내 협업 도구를 쓰는 직원(운영·영업·개발·디자인·재무) | 가정 — 작업 지시("문서·사람·업무를 찾는다") |
| 주요 작업 | ① 검색어로 문서·사람·업무를 한 번에 찾는다 ② 종류·팀·고친 날·형식·상태로 좁히고 관련도·최신으로 정렬한다 ③ 결과를 열어 내용을 확인한다(미리 보기) | 확인 — 작업 지시 |
| 빈도 | 하루 여러 번, 한 번에 검색어 1~3개 | 가정 |
| 들어오는 길 | 옆 메뉴의 "검색", 공유받은 주소(`?q=` 와 조건이 붙은 채로), 최근 검색어 | 가정 |
| 나가는 길 | 미리 보기로 확인한 뒤 다른 검색어로 다시 찾는다. 옆 메뉴로 다른 화면 | 가정 |

## 2. 정보 우선순위

| 순위 | 정보·행동 | 이 순위인 이유 |
|---|---|---|
| 1 | 결과 목록 — 제목(검색어 강조), 한 줄 내용, 누가·언제 | 찾던 것을 알아보는 것이 첫 일이다 |
| 2 | 검색어와 결과 건수, 종류 탭의 건수 | 검색이 맞게 됐는지, 어느 종류에 몰렸는지 먼저 판단한다 |
| 3 | 걸린 필터 | 필터가 걸린 줄 모르면 결과가 빠졌다고 오해한다(`PAT-LIST-03`) |
| 4 | 필터(팀·고친 날·문서 형식·업무 상태)와 정렬 | 결과가 많을 때만 쓴다 |
| 5 | 더 보기, 최근 검색어 | 다음 결과를 보거나 다시 찾을 때만 쓴다 |

- 주 행동: 검색(검색 칸 옆 강조 버튼 하나). 결과 영역에는 강조 버튼이 없다 — 결과를 고르는 것이 행동이다.

- 결과 행을 새로 만드는 이유: kit `ds-list__row` 는 제목·메타 한 줄씩이고 강조된 내용 줄(검색어 앞뒤 글)과 행 전체 포커스 이동이 없다. 같은 토큰으로 3줄(제목·내용·메타) 행을 만든다.
- `mark` 를 새로 꾸미는 이유: kit 에 검색어 강조 모양이 없다. 브라우저 기본 노랑은 토큰 밖 값이고 어두운 UI 에서 대비가 깨진다.
- 샘플 토큰: `--search-results-facets-w`(13.5rem — 옆 필터 열 폭. 가장 긴 선택지 "발표 자료" + 체크 + 건수가 한 줄에 든다), `--search-results-field-max`(40rem — 검색 칸 + 버튼의 최대 폭. 입력 칸 기본 최대 480 에 버튼을 더한 폭).
- 공용 부품에 필요한 것으로 보고: 검색어 강조(`mark`) 모양, 3줄 결과 행.
- 구현하며 샘플에서 메운 것(공용 부품에 필요한 것으로 보고):
  - 알약·동그라미 모양(`ds-chip`, `ds-chip__remove`)은 둥근 모서리 밖이 눌리지 않는다. 터치 44 상자의 네 모서리(6px 안쪽)를 `elementFromPoint` 로 보면 부모가 잡힌다 — 샘플 CSS 에서 투명 `::after`(inset 0)로 누르는 영역을 상자 전체로 넓혔다.
  - `base.css` 의 `* { overflow-wrap: break-word }` 가 상속을 끊어, flex 칸 안의 긴 이메일이 최소 폭을 줄이지 못하고 글자 200% 에서 문서를 가로로 넘겼다(375 에서 468px). 샘플에서 메타 칸마다 `min-width: 0; overflow-wrap: anywhere` 를 다시 줬다.
  - 결과를 다시 그리면 옆 패널을 연 버튼이 바뀌어 kit 가 닫을 때 본문 제목으로 보낸다 — 샘플이 `ds:panel-close` 에서 같은 결과의 새 버튼으로 돌려준다. 서랍도 넓은 폭으로 바뀌어 닫히면 kit 는 본문 제목으로 보낸다 — 샘플이 옆 열로 옮긴 같은 필터 칸으로 돌려준다.

| 종류 탭 | 탭 | ←→ Home End | 바로 바뀐다. 주소 `?type=doc`. 더 보기는 처음으로. 그 종류에 없는 필터 묶음은 숨긴다 |
| 필터 | 체크·라디오 | Space · 화살표 | 바로 걸러진다(0.1초 안, `PAT-LIST-13`). 주소 `?team=finance,ops` `?period=30d` `?format=sheet` `?status=doing`. live "결과 8건이 보여요" |
| 걸린 필터 빼기 | 칩 × | Enter | 그 조건만 빠진다. 포커스는 다음 칩 ×, 없으면 앞 칩 ×, 없으면 결과 건수 제목 |
| 모두 지우기 | 버튼 | Enter | 필터를 모두 지운다. 포커스는 결과 건수 제목 |
| 정렬 | 고르기 상자 | 화살표 | 관련도순(기본, 주소에 없음) · 최신순(`?sort=recent`). live "최신순으로 정렬했어요" |
| 결과 사이 이동 | — | ↑↓(결과 제목에서) | 같은 목록 안 앞뒤 결과 제목으로 포커스 |

## 10. 설계 메모 — 흔한 기본값과 비교

| 처음 안 | 흔한 기본값과 같은 점 | 바꾼 것 |
|---|---|---|
| 결과를 카드 격자로 | 카드만 나열한 화면 | 1열 목록. 제목·내용·메타를 위아래로 읽는다(검색 결과는 훑어 읽는다) |
| 검색어 강조를 노랑 바탕만으로 | 색만으로 구분(`CMP-SEL-04`) | 굵기 + 옅은 노랑, 고대비에서 시스템 `Mark` |
| 결과 없음에 빈 그림 + "결과가 없습니다" | 빈 영역 + 합니다체 | 맞춤법 제안 버튼, 철자 안내, 검색어 지우기. 필터 결과 없음은 다른 문장·행동 |
| 쪽 번호로 결과 넘기기 | 쪽 나누기 | 더 보기(작업 지시). 포커스는 새로 나온 첫 결과, 주소에 본 건수 |
| 필터를 결과 위 가로 줄에 모두 | 넓은 폭에서 필터 줄이 길어지고 좁은 폭에서 넘친다 | 넓은 폭은 옆 열, 좁은 폭은 같은 묶음을 서랍으로 옮긴다(같은 DOM 한 벌) |
| 결과를 누르면 새 화면으로 | 이 샘플에는 갈 화면이 없어 막힌 링크가 된다 | 비모달 미리 보기 패널(`CMP-TABLE-05`) |
| 결과 행마다 종류 아이콘(문서·업무)을 둥근 회색 타일에 | 제목마다 아이콘 타일(`ICN-02`). 문서·업무 탭에서는 모든 행이 같은 아이콘이라 식별하지 못한다(0회차 독립 채점 필수 지적) | 1회차에서 뺐다. 미리 보기 종류 줄·최근 검색어 시계 아이콘도 함께 뺐다. 사람 행의 이름 아바타만 남긴다(사람마다 다르다) |
| 처음 화면에 큰 그림·환영 문구 | 장식 빈 화면 | 최근 검색어와 자주 찾는 말 — 누르면 바로 찾는다 |
