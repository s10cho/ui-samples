## 7. 미확인

- 실제 Tab 키 이동: 채점 도구에 키 입력이 없어 `inert`·`aria-hidden`·`focus()` 실패로 대신 확인했다. 작성자는 CDP 키 입력으로 탭 이동 대화상자 흐름을 확인했다고 보고했다(검증되지 않음).
- 768·1440·320·글자 200% 의 스켈레톤 배치: 2회차는 375·1280 만 쟀다. 복제 방식은 폭과 관계없이 같은 DOM 을 쓴다.
- axe: 채점자는 돌리지 못했다. 저장소 CI(check-pages)가 상태 6개를 데스크톱·모바일에서 돌려 위반 0, 전송량 134.0KB/150KB 다(작성자 실행).
