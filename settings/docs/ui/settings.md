## 1. 사용자와 할 일

| 항목 | 내용 | 확인 / 가정 |
|---|---|---|
| 사용자 | 업무 서비스(상담·주문을 다루는 팀용 웹)를 쓰는 팀원. 팀 탭은 팀 소유자·관리자가 주로 쓴다 | 확인 — 작업 지시(업무 서비스의 설정 화면). 사용자 구성은 가정 |
| 주요 작업 | ① 내 계정 정보(이름·이메일·언어·시간대)를 고쳐 저장한다 ② 알림을 채널별로 켜고 끈다 ③ 2단계 인증을 켜고, 모르는 로그인이 있으면 다른 기기에서 로그아웃한다 ④ 구성원의 역할을 바꾸고 새 구성원을 초대한다 | 확인 — 작업 지시(탭 4개) |
| 빈도 | 드물다. 처음 쓸 때 한 번, 그 뒤 몇 주에 한 번. 팀 탭은 사람이 바뀔 때 | 가정 |
| 들어오는 길 | 옆 메뉴의 "설정", 알림 메일의 "알림 설정 바꾸기" 링크(`?tab=notifications`), 보안 알림 메일의 링크(`?tab=security`) | 가정 |
| 나가는 길 | 옆 메뉴로 다른 업무 화면. 저장하지 않은 변경이 있으면 먼저 묻는다 | 가정 |

## 2. 정보 우선순위

| 순위 | 정보·행동 | 이 순위인 이유 |
|---|---|---|
| 1 | 지금 고르고 있는 설정 묶음(탭)과 그 안의 값 | 설정 화면은 값을 확인하고 바꾸는 곳이다. 탭 이름이 찾는 말이다 |
| 2 | 바꾼 값이 적용됐는지 — 스위치는 바로 적용, 폼은 저장해야 적용 | 두 방식이 섞이면 무엇이 저장됐는지 모른다(`PAT-SET-02`) |
| 3 | 저장하지 않은 변경이 남아 있는지 | 떠나면 사라진다(`PAT-FORM-11`) |
| 4 | 보안 상태 — 2단계 인증 켜짐 여부, 로그인 중인 다른 기기 수 | 계정을 지키는 판단 근거다 |
| 5 | 팀 구성원과 역할 | 관리자가 사람을 바꿀 때 본다 |
| 6 | 위험 구역(팀 삭제) | 드물고 되돌릴 수 없다. 맨 아래 따로 둔다 |

- 주 행동: 탭마다 하나 — 계정 "계정 정보 저장", 알림 "방해 금지 시간 저장", 보안 "2단계 인증 켜기…", 팀 "구성원 초대"(`PAT-ARC-02`).

## 4. 컴포넌트

모두 kit(`shared/app`)의 기존 부품이다. 이 화면만 쓰는 꾸밈은 `settings/css/page.css` 에 `settings-` 이름으로 두고 `--ds-*` 토큰만 쓴다.

|---|---|---|---|---|
| 앱 틀·옆 메뉴 | 기존 | 서랍 | `surface-canvas` `surface-selected` | `CMP-NAV-06` `CMP-NAV-11` `CMP-NAV-14` |

| 폼·입력·고르기 상자 | 기존 | 글 · 이메일 · 고르기 | `line-control` `line-danger` | `CMP-INPUT-01` `CMP-INPUT-04` `CMP-INPUT-07` `CMP-SEL-11` |

### 저장 방식(설계 결정)

| 묶음 | 방식 | 이유 |
|---|---|---|
| 알림 받을 곳(스위치 12개) | 누르는 즉시 적용. 저장 버튼 없음. 실패하면 이전 값으로 되돌리고 배너 | `PAT-SET-01` `PAT-SET-06` |
| 계정 기본 정보 | 묶음마다 저장 버튼("계정 정보 저장") | 이메일·이름은 검증이 필요하고 함께 바뀐다 |
| 방해 금지 시간 | 묶음마다 저장 버튼("방해 금지 시간 저장"). 켜고 끄기도 스위치가 아니라 체크박스로 폼 안에 둔다 | 시작·끝 시각을 함께 정해야 의미가 있다. 저장 폼 안에 스위치를 섞지 않는다(`PAT-SET-02`) |
| 구성원 역할 | 고르는 즉시 적용. 권한을 낮추면(관리자 → 편집자 등) 그 행의 고르기 상자 옆에 "되돌리기" 버튼 | 표 안 저장 버튼은 무엇을 저장하는지 흐린다. 권한 회수는 되돌리기를 준다(`PAT-SET-04`). 배너로 띄우면 kit 이 배너까지 스크롤해 표를 놓치므로 행 안에 둔다 |
| 2단계 인증·다른 기기 로그아웃·초대·팀 삭제 | 대화상자에서 확인한 뒤 실행 | 사용자가 시작한 과정에 정보가 필요하거나 되돌리기 어렵다(`PAT-ARC-06`) |

- 저장 안 한 변경이 있는 채로 탭을 옮기면 대화상자로 묻는다: 닫기(남기) · 변경 버리고 이동 · 저장하고 이동.
- 옆 메뉴·머리줄 링크로 나가려 하면 같은 대화상자(나가기 문구)로 묻는다. 창 닫기·새로고침은 브라우저 기본 확인(`beforeunload`)이 묻는다.

## 6. 상호작용

| 동작 | 마우스·터치 | 키보드 | 결과 |
|---|---|---|---|
| 탭 옮기기 | 탭 누르기 | ← → Home End(탭에 포커스) | 패널이 바뀌고 주소 `?tab=`(계정은 지움), 문서 제목 "보안 — 설정". 고른 탭이 탭 줄에서 보이게 스크롤. 저장 안 한 변경이 있으면 먼저 대화상자 |
| 계정 저장 | "계정 정보 저장" | 폼 안에서 Enter | 칸 검증 → 버튼 "저장 중…" → "방금 저장했어요". 오류면 첫 오류 칸으로 포커스 |
| 변경 되돌리기 | "변경 되돌리기" | Enter | 마지막으로 저장한 값으로, 오류 지움, "변경을 되돌렸어요" 읽힘 |
| 칸 검증 | 칸을 떠날 때 | Tab | 오류면 칸 아래 글. 오류가 난 칸은 입력할 때마다 다시 검사해 맞으면 지운다(`PAT-FORM-01` `PAT-FORM-02`) |
| 알림 켜고 끄기 | 스위치 | Space | 바로 적용. "새 상담 배정 메일 알림을 켰어요" 읽힘. 실패하면 되돌림 + 배너 |
| 방해 금지 시간 | 체크·고르기 + 저장 | Space · 화살표 · Enter | 쓰기를 끄면 시각 고르기 비활성. 시작 = 끝이면 끝 칸 오류 |

| 팀 삭제 | "팀 삭제…" → 대화상자 | Enter | 팀 이름을 똑같이 쓰면 "팀 삭제" 활성 → 빈 상태로, 포커스는 "새 팀 만들기" |
| 대화상자 | — | Tab 은 안에서만, Esc | 닫으면 연 버튼으로 포커스 |
| 옆 메뉴 서랍 | 메뉴 버튼, 가림막 | Enter, Esc | 열면 닫기 버튼, 닫으면 메뉴 버튼으로 |
| 나가기 | 옆 메뉴·머리줄 링크 | Enter | 저장 안 한 변경이 있으면 대화상자(변경 버리고 나가기 · 저장하고 나가기) |

- 포커스 순서: 건너뛰기 링크 → 머리줄 → 옆 메뉴 → 페이지 머리 → 배너 → 탭(고른 탭 하나) → 패널(위에서 아래).
- 배너 버튼을 누른 뒤 포커스: 저장 실패 "다시 저장" → 저장 버튼(배너 버튼은 보조 모양 — 같은 일을 하는 주 버튼이 폼에 있다), 알림·역할 실패 배너 닫기 → 그 스위치·고르기 상자, 불러오기 "다시 불러오기" → 고른 탭.
- 좁은 폭(767 이하)에서 표는 행을 쌓는다. 빈 머리 띠는 숨기고, 알림 표는 "메일 [스위치] 앱 [스위치] 문자 [스위치]"를 한 줄에 늘어놓고, 로그인 기록은 기기 이름을 행 제목으로 맨 위에 둔다.
- 단축키: 없음.

## 10. 설계 메모 — 흔한 기본값과 비교

| 처음 안 | 흔한 기본값과 같은 점 | 바꾼 것 |
|---|---|---|
| 탭마다 맨 아래 "저장" 버튼 하나, 스위치까지 그 버튼으로 저장 | 토글 다섯 개 아래 저장 버튼(설정 화면 나쁜 예) | 스위치는 바로 적용, 저장 폼은 묶음마다 결과 동사 버튼("계정 정보 저장"). 방해 금지 켜기는 폼 안 체크박스 |
| 묶음마다 카드로 감싸기 | 모든 영역을 테두리 상자로 감싼 구성(`SHP-05`) | 묶음은 제목 + 설명 + 내용. 테두리 상자는 표와 위험 구역만 |
| 위험 구역을 빨간 바탕 + 왼쪽 두꺼운 빨간 선 | 카드 한쪽 두꺼운 색 테두리(`SLOP`·`SHP-07`) | 네 변 1px `line-danger` + 위험 버튼. 바탕은 본문과 같다 |
| 저장하면 "저장되었습니다" 토스트 | 토스트를 기본 알림으로(`CMP-FB-01`) | 저장 줄에 "방금 저장했어요", live 영역으로 읽힌다. 실패만 배너 |
| 프로필 사진·큰 인사말로 시작하는 계정 탭 | 첫 영역 히어로(`SLOP-10`) | 제목 한 줄 + 설명 한 줄, 바로 탭 |
| 알림을 종류별 스위치 하나씩 길게 나열 | 긴 스위치 목록 | 종류 × 채널 표(가로로 채널 비교). 좁은 폭은 행을 쌓는다 |
| 팀 삭제 버튼을 누르면 바로 "정말 삭제할까요? 확인/취소" | "확인"·"취소" 버튼(`CMP-BTN-10`·`CMP-OVL-09`) | 무엇이 사라지는지 적고 팀 이름을 쓰게 한 뒤 "팀 삭제". 보조 버튼은 "닫기" |
