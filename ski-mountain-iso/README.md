# 겨울 산 스키장 — 2D 아이소메트릭 첫 화면

3D 판(`../ski-mountain/`)과 같은 산, 같은 명소 5곳(리프트·초급 슬로프·상급 슬로프·산장·정상 전망대), 같은 설명 문구를 아이소메트릭 2D 그림(인라인 SVG)으로 다시 만든 정적 웹 페이지다.
두 방식을 견줘 보는 것이 목적이다. 화면 안의 "3D로 보기" 링크로 3D 판에 간다.
서버 코드와 빌드 단계 없이 파일만 올리면 동작한다.

- 화면 설계서: `docs/ui/ski-mountain-iso.md`
- 자체 점검 스크린샷: `docs/ui/review/ski-mountain-iso/20261117/self-*.png`
- 바로 보기: https://s10cho.github.io/ui-samples/ski-mountain-iso/
- 3D 판: https://s10cho.github.io/ui-samples/ski-mountain/

## 3D 판과 다른 점

| 항목 | 3D 판 | 이 판 |
|---|---|---|
| 그리기 | Three.js(WebGL) | 인라인 SVG. 산 높이 함수·슬로프 길·나무 자리는 3D 판과 같은 식·같은 씨앗 난수로 계산한다 |
| 보는 방향 | 처음 시점 남남동쪽, 끌어서 돌린다 | 같은 남남동쪽에 고정. 원근 없이 30° 로 내려본다 |
| 눈 내림 | 3D 장면 안 입자 | 그림 위 눈송이 층 세 겹(SVG 무늬 + CSS 애니메이션). 표지·버튼 아래에서만 떨어진다 |
| 첫 화면 | 포스터 이미지 → 3D 장면 | 그림이 HTML 과 함께 바로 보인다. 기다릴 것이 없다 |
| 조작 | 돌리기 · 가까이 · 멀리 · 처음 시점 | 옮기기(왼쪽·위쪽·아래쪽·오른쪽 보기) · 가까이 · 멀리 · 처음 시점. 2D 그림은 보는 방향이 하나라 돌리기 대신 끌기의 버튼 대안을 둔다(설계서 3-2절) |
| 파일로 열기 | 묶음 스크립트로 따로 부팅 | 같은 일반 스크립트 두 개가 그대로 돈다 |
| 첫 방문 전송량(압축) | 300KB 예산 | 약 95KB |

## 실행

두 방법 모두 같은 코드가 돈다.

| 여는 방법 | 차이 |
|---|---|
| `index.html` 더블클릭(`file://`) | 브라우저가 파일에서는 웹 글꼴을 막는다. 그래서 글꼴 파일을 아예 요청하지 않고 시스템 한글 글꼴로 보인다(콘솔 오류가 없다) |
| 정적 서버(http·https) | Pretendard 글꼴까지 설계서대로 보인다 |

```bash
python3 -m http.server 8000
```

서버로 열 때는 브라우저에서 그 서버 주소(포트 8000)를 열고 `ski-mountain-iso/` 로 들어간다. 파일을 고친 뒤에는 강력 새로고침(캐시 무시)을 한다.
정적 호스팅(GitHub Pages 등)에는 폴더를 그대로 올린다.
화면 스크립트를 받지 못하면 조작 버튼을 숨기고 명소 설명을 모두 펼친다. 목록은 그 설명으로 가는 링크가 된다. 그림은 HTML 안에 있어 그대로 보인다.

## 상태별 화면 띄우기

검수할 때 아래 쿼리 파라미터로 상태를 바로 띄운다. 여러 개를 `&` 로 이어 쓴다.

| 파라미터 | 보이는 것 |
|---|---|
| `?select=lift` | 명소 하나를 고른 상태. `lift` · `easy` · `expert` · `lodge` · `summit` |
| `?weather=snow` | 눈 내림 그림 + 눈송이 |
| `?motion=off` | 움직임 멈춘 상태(눈송이도 그 자리에 선다) |
| `?zoom=max` · `?zoom=min` | 가장 가까이 · 가장 멀리 본 상태. "가까이 보기"·"멀리 보기"가 비활성이 된다 |
| `?state=noscript` | 화면 스크립트를 쓸 수 없을 때의 화면 — 멈춘 그림 + 안내 배너 + 펼친 설명 + 설명으로 가는 목록 링크 |

- 움직임 줄이기는 브라우저·OS 설정(`prefers-reduced-motion: reduce`)으로 확인한다. 의자·스키어·눈송이가 멈춘 채 보인다.
- 조작 안내 문구는 입력 방법과 폭에 따라 하나만 보인다. 휠 안내는 넓은 폭(1024 이상) 마우스에서만 보인다. 그 조건에서만 휠이 확대한다.
- 스크린샷은 화면 크기 그대로 찍는다.

## 파일

| 경로 | 하는 일 |
|---|---|
| `index.html` | 화면 골격 + 산 그림(SVG)과 눈송이 층(`iso-scene` 표시 사이). 명소 설명이 HTML 에 들어 있어 스크립트가 꺼져도 읽힌다 |
| `css/tokens.css` | 디자인 토큰(설계서 4-1절). UI 토큰은 3D 판과 같고, 그림 색(`--iso-*`)과 눈 내림 색을 더했다 |
| `css/style.css` | 배치·컴포넌트·상태 스타일(3D 판의 화면 틀) |
| `css/scene.css` | 그림 면 클래스 → 그림 색 변수, 눈송이 층 |
| `js/iso-geom.js` | 투영·면 밝기·산 높이 함수·리프트 의자·스키어 자세 계산. 빌드 스크립트와 화면 스크립트가 같이 쓴다 |
| `js/app.js` | 보는 범위·선택·토글·끌기·확대·움직임·상태 처리 |
| `vendor/pretendard/` | Pretendard 1.3.9(SIL OFL). 화면 글자 전용 파일 + 다이나믹 서브셋(빠진 글자가 있을 때만 붙는다) |
| `tools/build-scene.mjs` | 산 그림과 눈송이 층을 계산해 `index.html` 에 넣는다(Node, 의존성 없음) |
| `tools/subset-font.py` | 화면 글자 전용 글꼴을 만든다 |

## 다시 만들기

| 언제 | 실행 |
|---|---|
| 그림 모양·자리·색 단계를 바꿨을 때(`js/iso-geom.js`·`tools/build-scene.mjs`) | `node tools/build-scene.mjs` |
| 화면 문구를 바꿔 새 글자가 생겼을 때 | `pip install fonttools brotli` 뒤 `python3 tools/subset-font.py <PretendardVariable.woff2 원본>` |

- 눈송이 바둑판 한 칸 크기(`tools/build-scene.mjs` 의 `FLAKES`)를 바꾸면 `css/tokens.css` 의 `--iso-flake-tile-*` 도 같은 값으로 바꾼다.
- 글꼴을 다시 만들지 않아도 화면은 깨지지 않는다. 화면 스크립트가 page subset 에 없는 글자를 찾으면 다이나믹 서브셋을 붙이고 그 조각만 받는다.
