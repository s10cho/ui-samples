# 지구 궤도의 작은 정거장 — 3D 첫 화면(어두운 UI)

지구 궤도를 도는 가상의 작은 정거장을 3D로 보여 주는 정적 웹 페이지다. 명소 5곳(거주 모듈·실험실 모듈·태양 전지판·도킹 포트·관측 창)이 있고, 정거장이 지구의 낮 쪽 위에 있을 때와 밤 쪽 위에 있을 때를 바꿔 볼 수 있다.
실존 정거장·우주 기관·우주선을 본뜨지 않았다. 서버 코드 없이 정적 파일로 동작한다. 화면 틀은 3D 공용 뼈대(`shared/scene3d/`)를 쓰고, 배포할 때 이 폴더와 합쳐 조립한다.

이 샘플의 과제는 **어두운 화면의 UI** 다. 패널·버튼·표지를 어두운 바탕에 맞춘 토큰 한 벌로 만들었다(설계서 4-1절에 대비 계산값).

- 화면 설계서: `docs/ui/space-station.md`
- 자체 점검 스크린샷: `docs/ui/review/space-station/20261117/self-*.png`
- 바로 보기: https://s10cho.github.io/ui-samples/space-station/

## 실행

이 폴더에는 이 화면만의 파일(장면·문구·토큰·고유 스타일)만 있다. 화면 틀(부팅·배너·시점 버튼·포스터 배치 스크립트, 공통 스타일, 도구)은
저장소의 `shared/scene3d/` 에 있고, 조립할 때 이 폴더와 합쳐진다(`docs/platform.md`). 저장소 루트에서 조립한 뒤 `_site/space-station/` 를 연다.

```bash
node tools/build-site.mjs --only space-station   # _site/space-station/ — 공용 뼈대 복사 → 이 폴더 복사 → dist/app.bundle.js 생성
python3 -m http.server 8000 --directory _site
```

| 여는 방법 | 쓰는 스크립트 | 차이 |
|---|---|---|
| `_site/space-station/index.html` 더블클릭(`file://`) | `dist/app.bundle.js` — 조립할 때 만든 한 파일 묶음(일반 스크립트) | 브라우저가 파일에서는 ES 모듈과 웹 글꼴을 막는다. 그래서 묶음 스크립트를 쓰고, 글자는 시스템 한글 글꼴로 보인다(콘솔에 글꼴 차단 메시지가 남는다) |
| 정적 서버(http·https) | `js/main.js` — ES 모듈. 3D 파일은 필요할 때 받는다 | 느린 연결 안내·Pretendard 글꼴까지 설계서대로 동작한다 |

서버로 열 때는 브라우저에서 그 서버 주소(포트 8000)의 `/space-station/` 를 연다. 파일을 고친 뒤에는 다시 조립하고 강력 새로고침(캐시 무시)을 한다.
조립된 `_site/space-station/` 폴더는 혼자 완결된다. 정적 호스팅에는 그 폴더를 그대로 올린다.
화면 스크립트를 받지 못했거나 6초 안에 시작하지 않으면, 동작하지 않는 버튼을 숨기고 명소 설명을 모두 펼친다.

## 상태별 화면 띄우기

검수할 때 아래 쿼리 파라미터로 상태를 바로 띄운다. 여러 개를 `&` 로 이어 쓴다.

| 파라미터 | 보이는 것 |
|---|---|
| `?select=dock` | 명소 하나를 고른 상태. `habitat` · `lab` · `solar` · `dock` · `window` |
| `?side=night` | 지구 밤 쪽 장면(기본은 낮 쪽 `day`) |
| `?motion=off` | 움직임 멈춘 상태 |
| `?state=nowebgl` | 3D 실패(WebGL 없음) — 포스터 + 배너 + 목록 |
| `?state=slow` | 느린 연결 — 0.3초 뒤 진행 문구, 10초 뒤 "3D 없이 보기" 배너. 그동안 포스터가 보인다 |
| `?state=lost` | 장면 멈춤 — 준비 0.8초 뒤 컨텍스트를 잃고, 3초 뒤 "다시 그리기" 배너 |
| `?quality=high` · `?quality=low` | 품질 단계 고정(자동 낮춤 끔). 낮은 품질은 그림자·안티앨리어싱을 끄고 별·도시 불빛을 반으로 줄인다 |
| `?poster=day&size=wide` 등 | 포스터 촬영 모드. 장면만 보인다. `poster` 는 `day` · `night`, `size` 는 `wide` · `medium` · `narrow` |

- 움직임 줄이기는 브라우저·OS 설정(`prefers-reduced-motion: reduce`)으로 확인한다.
- 스크린샷은 화면 크기 그대로 찍는다. 전체 페이지 캡처는 창 크기를 바꾸는 순간 캔버스가 지워져 장면이 빈 우주로 찍힐 수 있다.
- 헤드리스 크롬은 GPU 없이 소프트웨어로 그린다. 프레임 시간은 실제 기기에서 잰다.
- 검수용 값: 개발자 도구 콘솔에서 `spaceStation.scene.stats()`(그리기 호출·삼각형·점·지구 면 수), `spaceStation.scene.cameraState()`(시점·실효 거리·렌즈 배율·장면 시각).

## 포스터와 3D 첫 화면을 맞추는 방법

바탕 샘플 검수에서 "포스터 → 3D 교체 때 장면이 움직인다"는 지적이 남았다. 이 샘플은 처음부터 아래처럼 만들었다.

| 무엇 | 어떻게 |
|---|---|
| 카메라 위치 | 폭 구간(넓은·중간·좁은)마다 하나로 고정한다(`js/framing.js` 의 `classDistance`). 포스터도 같은 위치에서 찍는다 |
| 화면 비율 차이 | 카메라를 움직이지 않고 렌즈 배율(`camera.zoom`)과 시야 이동(`setViewOffset`)으로만 맞춘다. 포스터 캔버스가 큰 만큼은 시야만 넓힌다 |
| 빈 자리 | 장면에서 정보 패널·장면 토글 묶음·시점 버튼 묶음이 차지하는 실제 크기를 빼고, 남은 자리 가운데에 정거장을 맞춘다. 글자 200% 에서 버튼이 두 줄이 되어도 정거장이 버튼에 깔리지 않는다 |
| 품질 단계 | 그 폭의 기본 단계로 찍는다. 넓은 = 높은 품질, 중간·좁은 = 낮은 품질. 낮은 품질의 별·도시 불빛은 높은 품질 점들의 앞부분과 같은 점이다 |
| 움직이는 물체 | 3D 첫 프레임을 포스터와 같은 장면 시각(19.8초)에서 시작한다. 화물선·전지판·지구 회전·별 반짝임이 모두 장면 시각의 함수다 |
| 로딩 중 버튼 | 움직임 토글과 시점 버튼은 로딩 중 자리를 비워 두고 보이지만 않게 한다(`visibility`). 빈 자리 계산이 3D 준비 전후로 같다 |

자체 점검(헤드리스 크롬, 같은 폭에서 `?state=slow` 포스터와 `?motion=off` 3D를 찍어 픽셀 비교, 표지는 숨김):

| 폭 | 장면 | 가장 잘 맞는 어긋남 | 평균 차이(0~255) |
|---|---|---|---|
| 1280×800 | 낮 쪽 | 0, 0 | 3.82 |
| 1280×800 | 밤 쪽 | 0, 0 | 0.86 |
| 768×1024 | 밤 쪽 | 0, 0 | 1.10 |
| 375×812(2배 화면) | 낮 쪽 | 기기 1px(CSS 0.5px) | 3.65 |

차이는 포스터 WebP 압축과 가장자리 계단(안티앨리어싱)에서 나온다. 겹쳐 본 그림은 `docs/ui/review/space-station/20261117/self-overlay-*.png` 다.

## 파일

| 경로 | 하는 일 |
|---|---|
| `index.html` | 화면 골격. 명소 설명이 HTML 에 들어 있어 스크립트가 꺼져도 읽힌다. `color-scheme`·`theme-color` 를 어두운 바탕으로 선언한다 |
| `css/tokens.css` | 디자인 토큰(설계서 4-1절, 어두운 UI 한 벌). 화면 코드는 이 변수만 쓴다 |
| `css/style.css` | 이 화면만의 스타일(장면 바탕색 등). 공통 배치·컴포넌트·상태는 공용 뼈대 `css/shell.css`·`css/shell-landmarks.css` |
| `js/tokens.js` | 3D 장면 색·빛·시점·움직임 주기·예산 값, 폭 경계 |
| `js/main.js` | 화면 설정 — 장면 갈래 토글 값·문구·처음 시점 맞춤. 부팅·선택·토글·배너·상태 처리·포스터 배치는 공용 뼈대 `js/shell/` |
| `js/framing.js` | 처음 시점 맞춤 계산 — 폭 구간별 카메라 거리, 실효 거리, 포스터 자리. 3D와 포스터가 같은 식을 쓴다(three.js 없이 돈다) |
| `js/scene/scene.js` | 3D 장면(정거장·화물선·지구·구름·대기 띠·도시 불빛·별·카메라·표지). 지구는 보이는 윗부분만 면으로 만든다 |
| `assets/poster-*.webp` | 포스터 6장(낮 쪽·밤 쪽 × 좁은·중간·넓은). 3D 준비 전과 실패 때 보인다 |
| `vendor/three/` | Three.js 0.187.0 중 쓰는 클래스 25개만 묶은 파일(MIT) |
| `vendor/pretendard/` | Pretendard 1.3.9(SIL OFL). 화면 글자 전용 파일(글자 287개). 다이나믹 서브셋(빠진 글자 대비)은 조립 때 `shared/common/` 에서 들어온다 |
| `sample.config.json` | 조립 설정 — 공용 뼈대 이름(`scene3d`), 조립 뒤 실행할 명령, 자동 검수 상태 목록 |
| 공용 뼈대(조립 때 들어온다) | `css/shell.css`·`css/shell-landmarks.css`·`js/shell/`·`tools/` — 저장소의 `shared/scene3d/`. 이 폴더에는 없다 |
| `dist/app.bundle.js`(조립 때 생긴다) | 파일로 열 때(`file://`) 쓰는 한 파일 묶음. 생성물이라 저장소에 넣지 않는다 |

## vendor 파일 다시 만들기

| 언제 | 실행 |
|---|---|
| `js/` 에서 `'three'` 의 새 이름을 가져왔을 때 | 저장소 루트에서 `node shared/scene3d/tools/build-three.mjs space-station` 뒤 다시 조립 |
| `js/` 아래 코드나 공용 뼈대를 고쳤을 때 | 다시 조립한다(`node tools/build-site.mjs --only space-station`). `dist/app.bundle.js` 도 이때 다시 만든다 |
| 화면 문구를 바꿔 새 글자가 생겼을 때 | `pip install fonttools brotli` 뒤 저장소 루트에서 `python3 shared/scene3d/tools/subset-font.py <PretendardVariable.woff2 원본> space-station` — 공용 뼈대의 문구도 같이 모은다. HTML·JS 주석 속 글자는 모으지 않는다(`pyftsubset` 이 PATH 에 있어야 한다) |
| 장면 모양·시점·색을 바꿨을 때 | `?poster=day&size=wide`·`?poster=night&size=wide` 를 2400×1400 창(화면 배율 1)에서, `size=medium` 을 2000×1120, `size=narrow` 를 900×1170 창에서 찍어 `assets/poster-<지구 쪽>-<size>.webp` 로 바꾼다. 캔버스 크기는 `js/tokens.js` 의 `POSTER` 와 같아야 한다(다르면 배치하지 않고 가득 채우기로 둔다) |

- 포스터는 전송량 예산 때문에 목표 용량으로 줄였다: `cwebp -size <바이트> -pass 6 -m 6 -sharp_yuv`. 넓은 48,000 · 중간 40,000 · 좁은 20,000 바이트 목표.
- 글꼴을 다시 만들지 않아도 화면은 깨지지 않는다. 빠진 글자만 다이나믹 서브셋 조각에서 받는다.
