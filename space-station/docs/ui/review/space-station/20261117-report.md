## 4. 고치면 좋은 것

| # | 규칙 ID | 위치 | 증거 | 고칠 방향 | 처리 |
|---|---|---|---|---|---|
| 1 | 규칙 없음(영역 2) — 반복(city-night 4절 2 와 같은 유형, 원인은 다름) | 자동 회전 1280·768·375·1440, 1024 첫 프레임, 667×375, 1024 글자 200% | M2·M3. 원인은 표지끼리 겹침(`js/scene/scene.js:887`)과 몸통에 가림(`852-858`). 설계서 6절은 토글 아래로 숨는 경우만 다뤘다 | 겹친 표지를 숨기지 말고 위아래로 비켜 놓거나, 자동 회전 범위·방향을 표지가 가리지 않는 쪽으로 정한다 | 남음 |

참고(감점 없음):
- "3D 없이 보기"를 누르면 포스터가 34px 내려간다(M10, C15 → C31). 로딩의 시점 버튼은 `visibility:hidden` 이고 fallback 은 `display:none` 이라(`css/style.css:617-625`) 빈 자리 아래 여백이 0 이 된다(`js/main.js:439`). fallback 도 버튼 자리를 남기면 된다.
- 밤 쪽 정거장 몸통이 어둡다. 윤곽은 켜진 창·금빛 띠·도킹 고리로 읽힌다(C09·C12·C14·C22). 충분한지는 실기기에서 사람이 판단해야 한다(추정).
- 3D 실패 화면에서 배너 둘째 문장과 고르는 법 줄이 같다(C13). city-night r1 과 같다.
- CLR-DARK-01 예외는 설계서에만 적혀 있다. DESIGN.md 를 세울 때 "허용"으로 옮기고, "장면 때문에 어두운 UI 한 벌만 두는 화면"을 규칙 후보로 올리기를 권한다.
- 거의 검정에 가까운 남색 + 강조색 하나는 SLOP-02 군집 2 와 모양이 비슷하지만, 강조색이 채도를 낮춘 호박색이고 어두운 바탕은 요청이 정했으므로 위반이 아니다.
