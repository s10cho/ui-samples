# 사계절 산사 마을 — 3D 첫 화면

산 중턱의 가상의 오래된 절과 그 아래 작은 마을을 3D로 보여 주는 정적 웹 페이지다. 명소 5곳(산문·본당·석탑·연못과 돌다리·종각)이 있다.
계절을 봄·여름·가을·겨울 4개 가운데 하나로 고를 수 있다. 서버 코드 없이 정적 파일로 동작한다. 화면 틀은 3D 공용 뼈대(`shared/scene3d/`)를 쓰고, 배포할 때 이 폴더와 합쳐 조립한다.

- 화면 설계서: `docs/ui/temple-seasons.md`
- 바로 보기: https://s10cho.github.io/ui-samples/temple-seasons/
- 실존 장소·실제 사찰을 본뜨지 않은 가상의 장소다. 종교 의식이나 특정 종단을 다루지 않고 건축과 풍경으로만 보여 준다.

## 실행

이 폴더에는 이 화면만의 파일(장면·문구·토큰·고유 스타일)만 있다. 화면 틀(부팅·배너·시점 버튼·포스터 배치 스크립트, 공통 스타일, 도구)은
저장소의 `shared/scene3d/` 에 있고, 조립할 때 이 폴더와 합쳐진다(`docs/platform.md`). 저장소 루트에서 조립한 뒤 `_site/temple-seasons/` 를 연다.

```bash
node tools/build-site.mjs --only temple-seasons   # _site/temple-seasons/ — 공용 뼈대 복사 → 이 폴더 복사 → dist/app.bundle.js 생성
python3 -m http.server 8000 --directory _site
```

| 여는 방법 | 쓰는 스크립트 | 차이 |
|---|---|---|
| `_site/temple-seasons/index.html` 더블클릭(`file://`) | `dist/app.bundle.js` — 조립할 때 만든 한 파일 묶음(일반 스크립트) | 브라우저가 파일에서는 ES 모듈과 웹 글꼴을 막는다. 그래서 묶음 스크립트를 쓰고, 글자는 시스템 한글 글꼴로 보인다 |
| 정적 서버(http·https) | `js/main.js` — ES 모듈. 3D 파일은 필요할 때 받는다 | 느린 연결 안내·Pretendard 글꼴까지 설계서대로 동작한다 |

서버로 열 때는 브라우저에서 그 서버 주소(포트 8000)의 `/temple-seasons/` 를 연다. 파일을 고친 뒤에는 다시 조립하고 강력 새로고침(캐시 무시)을 한다.
조립된 `_site/temple-seasons/` 폴더는 혼자 완결된다. 정적 호스팅에는 그 폴더를 그대로 올린다.
화면 스크립트를 받지 못했거나 6초 안에 시작하지 않으면, 동작하지 않는 버튼을 숨기고 명소 설명을 모두 펼친다.

## 상태별 화면 띄우기

검수할 때 아래 쿼리 파라미터로 상태를 바로 띄운다. 여러 개를 `&` 로 이어 쓴다.

| 파라미터 | 보이는 것 |
|---|---|
| `?select=hall` | 명소 하나를 고른 상태. `gate` · `hall` · `pagoda` · `pond` · `bell` |
| `?season=spring` | 그 계절로 시작. `spring` · `summer` · `autumn` · `winter`. 기본은 가을(`autumn`)이고, 가을이면 주소에서 지운다 |
| `?motion=off` | 움직임 멈춘 상태(꽃잎·낙엽·눈, 새, 굴뚝 연기, 연못 물결, 자동으로 둘러보기) |
| `?state=nowebgl` | 3D 실패(WebGL 없음) — 포스터 + 배너 + 목록 |
| `?state=slow` | 느린 연결 — 0.3초 뒤 진행 문구, 10초 뒤 "3D 없이 보기" 배너 |
| `?state=lost` | 장면 멈춤 — 준비 0.8초 뒤 컨텍스트를 잃고, 3초 뒤 "다시 그리기" 배너 |
| `?quality=high` · `?quality=low` | 품질 단계 고정(자동 낮춤 끔) |
| `?poster=autumn&size=wide` 등 | 포스터 촬영 모드. 장면만 보인다. `poster` 는 계절 4개, `size` 는 `wide` · `medium` · `narrow` |

- 계절은 장면 오른쪽 위 묶음 버튼(라디오 4칸)으로 고른다. Tab 으로 들어가면 고른 칸에 포커스가 가고, 화살표로 옮기며 고른다.
- 움직임 줄이기는 브라우저·OS 설정(`prefers-reduced-motion: reduce`)으로 확인한다.
- 스크린샷은 화면 크기 그대로 찍는다. 전체 페이지 캡처는 창 크기를 바꾸는 순간 캔버스가 지워져 장면이 빈 하늘로 찍힐 수 있다.
- 헤드리스 크롬은 GPU 없이 소프트웨어로 그린다. 프레임 시간은 실제 기기에서 잰다.

## 처음 시점과 포스터

- 카메라 자리(방향·거리·중심점)는 화면 크기와 상관없이 하나다. 화면 크기에 맞추는 일은 시야 배율(`camera.zoom`)과 시야 이동(`setViewOffset`)으로만 한다(`js/framing.js`).
- 그래서 포스터는 3D 첫 프레임을 늘리고 옮긴 그림과 같다. 포스터는 같은 카메라 자리, 그 폭의 기본 품질(넓은 폭 높은 품질, 좁은·중간 폭 낮은 품질), 같은 장면 시각(입자·새·연기·물결 자리)으로 찍었다.
- 처음 시점은 장면 토글 묶음의 실제 아래 끝 + 표지 높이부터 시점 버튼 묶음의 실제 위 끝까지를 맞춤 영역으로 쓴다. 글자를 키우거나 버튼 묶음이 두 줄이 돼도 명소가 버튼 아래로 들어가지 않는다.
- 자동으로 둘러보기는 한 바퀴 돌지 않고 좌우로 ±18° 만 흔든다. 회전 중심이 본당이라 가장 높은 명소(본당)의 표지는 그 자리에 머문다.
- 포스터는 그 폭의 흔한 화면 크기(넓은 폭 1024×768~1920×1200, 중간 폭 400~1023, 좁은 폭 320~599, 375 폭 글자 200% 포함)를 덮는다. 그보다 크거나 아주 납작한 창(예: 1366×600, 320 폭 글자 200%)은 가득 채우기(cover)로 둔다.

## 파일

| 경로 | 하는 일 |
|---|---|
| `index.html` | 화면 골격. 명소 설명이 HTML 에 들어 있어 스크립트가 꺼져도 읽힌다 |
| `css/tokens.css` | 디자인 토큰(설계서 4-1절). 화면 코드는 이 변수만 쓴다 |
| `css/style.css` | 이 화면만의 스타일(장면 바탕색 등). 공통 배치·컴포넌트·상태는 공용 뼈대 `css/shell.css`·`css/shell-landmarks.css` |
| `js/tokens.js` | 3D 장면 색·빛(계절별)·명소 자리·시점·포스터·예산 값, 폭 경계 |
| `js/main.js` | 화면 설정 — 장면 갈래 토글 값·문구·처음 시점 맞춤. 부팅·선택·토글·배너·상태 처리·포스터 배치는 공용 뼈대 `js/shell/` |
| `js/framing.js` | 처음 시점·포스터 맞춤 계산 — 3D와 포스터가 같은 식을 쓴다(three.js 없이 돈다) |
| `js/scene/scene.js` | 3D 장면(높이 함수 지형·절·마을·연못·나무·계절 입자·카메라·표지) |
| `assets/poster-*.webp` | 포스터 12장(계절 4개 × 좁은·중간·넓은). 첫 방문에는 지금 계절·지금 폭의 1장만 받는다 |
| `vendor/three/` | Three.js 0.187.0 중 쓰는 클래스만 묶은 파일(MIT) |
| `vendor/pretendard/` | Pretendard 1.3.9(SIL OFL). 화면 글자 전용 파일. 다이나믹 서브셋(빠진 글자 대비)은 조립 때 `shared/common/` 에서 들어온다 |
| `sample.config.json` | 조립 설정 — 공용 뼈대 이름(`scene3d`), 조립 뒤 실행할 명령, 자동 검수 상태 목록 |
| 공용 뼈대(조립 때 들어온다) | `css/shell.css`·`css/shell-landmarks.css`·`js/shell/`·`tools/` — 저장소의 `shared/scene3d/`. 이 폴더에는 없다 |
| `dist/app.bundle.js`(조립 때 생긴다) | 파일로 열 때(`file://`) 쓰는 한 파일 묶음. 생성물이라 저장소에 넣지 않는다 |

## vendor 파일 다시 만들기

| 언제 | 실행 |
|---|---|
| `js/` 에서 `'three'` 의 새 이름을 가져왔을 때 | 저장소 루트에서 `node shared/scene3d/tools/build-three.mjs temple-seasons` 뒤 다시 조립 |
| `js/` 아래 코드나 공용 뼈대를 고쳤을 때 | 다시 조립한다(`node tools/build-site.mjs --only temple-seasons`). `dist/app.bundle.js` 도 이때 다시 만든다 |
| 화면 문구를 바꿔 새 글자가 생겼을 때 | `pip install fonttools brotli` 뒤 저장소 루트에서 `python3 shared/scene3d/tools/subset-font.py <PretendardVariable.woff2 원본> temple-seasons`(`pyftsubset` 이 PATH 에 있어야 한다). 공용 뼈대의 문구도 같이 모은다. HTML·JS 주석 속 글자는 모으지 않는다 |
| 장면 모양·시점·색을 바꿨을 때 | 포스터 12장을 다시 찍는다. 창(뷰포트)을 `js/tokens.js` 의 `POSTER` 크기와 같게 하고(기기 배율 1) `?poster=<계절>&size=<폭>` 을 연다. 넓은 폭 1430×858, 중간 폭 1134×804, 좁은 폭 740×1210. `html[data-poster-ready="true"]` 가 되면 화면을 찍어 `assets/poster-<계절>-<폭>.webp` 로 바꾼다(이번에는 `cwebp -q 55 -m 6 -af`, 좁은 폭 `-q 62`). 크기가 토큰과 다르면 배치하지 않고 가득 채우기로 둔다 |

글꼴을 다시 만들지 않아도 화면은 깨지지 않는다. 빠진 글자만 다이나믹 서브셋 조각에서 받는다.
